# AItea · 茶渡

面向六堡茶出口印度尼西亚、新加坡的资料与办理工作台。

## 功能模块

| 模块       | 功能                                       |
| ---------- | ------------------------------------------ |
| 账号与权限 | 登录、账号审批与业务隔离                   |
| 办理流程   | 两国线上／线下四条路线、任务编排与配置发布 |
| 对话与事实 | 节点对话、事实确认与办理材料协作           |
| 持续采集   | 来源清单、代理下载、周期更新与版本留存     |
| 资料与检索 | 原件管理、MinerU 解析、RAGFlow 索引与检索  |
| 法律分析   | 事实分析、依据引用与人工复核               |
| 文稿管理   | 文稿生成、人工编辑与版本历史               |

## 文件结构

```text
backend/       FastAPI 后端、DDD 业务上下文与测试
frontend/      Next.js 前端及 /tea 工作区
config/        流程配置、来源清单与校验规则
scripts/       开发、采集和运维脚本
deploy/        部署配方
docs/          专题文档与索引
samples/       演示材料
data/          数据库、原件、索引与私有配置（不提交）
.dev/          运行状态、日志与工具缓存（不提交）
Makefile       统一命令入口
```

## 开发与启动

在仓库根目录执行，环境准备见 [开发环境](docs/DEVELOPMENT.md)。

| 命令              | 用途                                   |
| ----------------- | -------------------------------------- |
| `make setup`      | 安装锁定依赖                           |
| `make dev`        | 自动准备依赖，启动前后端热更新开发环境 |
| `make dev-status` | 查看服务状态                           |
| `make dev-stop`   | 停止当前工作树的前后端                 |
| `make check`      | 运行后端检查、前端类型与交互测试       |
| `make build`      | 构建前端生产产物，执行前先停止开发服务 |
| `make start`      | 启动已构建的生产预览                   |

默认入口：[工作台](http://127.0.0.1:3000/tea) · [管理后台](http://127.0.0.1:3000/tea/admin)。

架构、接口、配置、部署、采集和迁移等说明见 [文档索引](docs/README.md)；开发约定见 [AGENTS.md](AGENTS.md)。
