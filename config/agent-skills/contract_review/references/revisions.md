# 合同修改与对照交付

借鉴 Legal-Agent-Skills 的原条款与完整修改文字对应，以及 LegalQuants redlines 的修改定位、格式与修订信息区分。未安装 @houfu/redlines，也未复制或执行上游脚本。

先明确需要审查意见、完整替换条文、修改对照，还是保留模板的 Word 修改稿。每处修改对应文件版本、条号、实际原文与原因；没有看到的条文不能补作已经存在。金额、比例、期限与双方责任变动属于建议，未获用户指示不得写成已经约定。

需要文件时使用真实文档工具：list_documents 取得编号与版本，inspect_document_file 分页读取实际位置，edit_document_file 传原文、part 和命中次数，另存副本并保留原件。用户要求其他文字不变时不得通过 create_document_file 重写全文。需要新建审查意见或修改对照表时可用 create_document_file 生成 DOCX/PDF，表内保留原条款、修改后全文与理由。

现有编辑工具不生成 Word 原生插入、删除修订标记，不支持接受或拒绝修订，也不编辑已有修订、域或数字签名。明确要求原生红线时，说明该文件操作尚未支持，可先交付完整修改建议与对照内容；不得以普通另存稿、删除线或颜色冒称原生修订稿。

文件工具完成结构检查及业务保存后，使用程序返回的真实下载链接。不声称已经核对打印版式、逐页视觉效果或对外签署条件。保留仍需确认的条款与材料缺项，不将文件成功生成当作法律审查通过。
