# 文件格式与调用示例

所有工具绑定当前账号和业务。只传服务端返回的 document_id 与 version，不传任意本机位置、URL 或账号。工具每轮最多准备三份文件；同一正文需要 Word 与 PDF 时，可分别生成两份。

## Word、PDF 与文本

`create_document_file` 示例：

```json
{"filename":"催款函.docx","format":"docx","content":"# 催款函\n致：[待补充]\n请贵方按照合同支付已到期货款。\n\n| 项目 | 内容 |\n| --- | --- |\n| 到期货款 | [待补充] |\n| 收款账号 | [待补充] |"}
```

PDF 使用同一正文、`format: "pdf"` 和 `.pdf` 文件名。使用本地中文字体编码生成普通文稿，不依赖 LibreOffice 或外部转换服务。支持基础标题、段落和表格；不将原有 Word 重排后冒称保留模板。MD/TXT 直接保留文本，CSV 保留提供的分隔符与前导零；Excel 打开CSV的自动类型转换不受本工具控制。

修改 Word 或 PPT 的某段：先检查文件，再逐字使用返回的 part 与 old_text。

```json
{"document_id":"实际编号","version":1,"filename":"催款函-修改.docx","replacements":[{"part":"word/document.xml","old_text":"支付已到期货款","new_text":"支付已到期货款人民币[待补充]元","expected_count":1}]}
```

替换可跨文字运行区间，保留原样式与非目标内容。新增文字采用起始文字的样式；不重建整个段落。目标段落含域、修订、制表符或手动换行时会说明不支持，不能通过全文重写绕过原件保留要求。表格内文字、页眉页脚按实际 part 定位。非目标包部件保持原字节；未进行页面渲染，不能承诺视觉效果完全相同。

文本文件精确替换时省略 part，保留 UTF-8 BOM 与原有换行。其他编码先说明需要 UTF-8 副本，不悄悄转码。

## Excel

新建示例，content 是 JSON 字符串：

```json
{"filename":"茶叶报价.xlsx","format":"xlsx","content":"{\"sheets\":[{\"name\":\"报价\",\"rows\":[[\"产品编号\",\"品名\",\"单价\"],[\"001\",\"六堡茶\",120]]}]}"}
```

最多12张表，每表1000行30列，单元格最多4000字。保留文字类型和前导零。以 `=` 开头的内容作为文字保存，不自动执行公式、链接或外部数据。

编辑示例：

```json
{"document_id":"实际编号","version":1,"filename":"茶叶报价-修改.xlsx","cells":[{"sheet":"报价","cell":"C2","expected_value":120,"value":125}]}
```

检查返回 sheet、cell、value 和 formula；以实际原值填写 expected_value。只支持已存在的非公式单元格，公式不能改成显示值。直接修改对应 XML 单元格，其他单元格、样式、图片、图表和包部件保留。公式未计算，相关缓存值可能仍是修改前的结果，应在办公软件中重新计算后使用。合并单元格需选择实际锚点，不向非锚点填值。

## PPT

新建示例：

```json
{"filename":"出口准备.pptx","format":"pptx","content":"{\"slides\":[{\"title\":\"六堡茶出口准备\",\"bullets\":[\"确认海外买方和进口商\",\"核对产品、包装和交货条件\"]}]}"}
```

最多30页，每页标题100字、正文8项且每项250字。使用基础标题和正文布局，不声称完成品牌设计或长文字溢出检查。编辑现有PPT按检查返回的 `ppt/slides/slideN.xml` 替换原文，保留其他页面、母版、图片和未修改部件。暂不支持图表数据编辑、SmartArt重排、模板自动适配或转PDF。

## 检查与限制

新建和编辑均在有超时、内存和体积限制的本地工作进程中执行，最大文件20 MB。Office包展开最多50 MB和2000项；PDF读取最多100页。工具未接入任意脚本执行，不执行文件中的程序或网络请求。

引用真实依据、限定事实和草稿用途由主 Agent 保留在正文中。结构检查通过只说明文件能够读取，不证明法律内容正确，也不代表页面已视觉验收。
