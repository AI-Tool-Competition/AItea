# 茶叶业务合同模板与文件格式

先复用当前用户和材料已说明的交易。问“代理”时区分介绍客户、代签销售、受托办理出口、买断经销；这些安排的签约、收款和责任不同，不能共用一份代理合同。仅在无法确定本次合同关系时简短追问，其余姓名、金额、日期等缺项保留[待补充]继续起草。常用模板可直接用read_contract_template按tea_purchase、tea_export、export_agency、tea_distribution读取全文，不需要先加载本说明或搜索上传资料；下表资源供load_skill按需读取。

| 实际交易 | 用load_skill读取的资源 | 适用边界 |
| --- | --- | --- |
| 茶农、工厂或贸易商之间的境内茶叶采购 | assets/contracts/tea-purchase.md | 选择鲜叶、毛茶或成品茶，核对实际质量和材料需求 |
| 中国卖方向境外买方销售茶叶 | assets/contracts/tea-export.md | 单批或明确订单的跨境买卖；目的地、进口商和贸易条件按事实确定 |
| 委托外贸企业办理出口及结算服务 | assets/contracts/export-agency.md | 先确认以谁的名义对外签约；买断转售另用购销合同 |
| 经销商购入茶叶后自行转售 | assets/contracts/tea-distribution.md | 可用于国内或跨境经销；独家、地域、品牌授权及终止按具体约定 |

四份均为茶渡业务改编稿。境内采购以总局2025年农副产品买卖示范文本为主要结构参考，并吸收广州茶叶文本的行业字段；出口销售参考开源供货协议的订单、交付、验收和单证结构。委托出口与经销文本为茶渡编写的业务初稿。不得冠以“政府发布”“官方标准合同”、套用官方示范文本编号，或声称已经律师审核。

用户只要“官方原版”时提供references/contract-sources.md中的官网和原始下载链接，不将改编稿冒充原件。需要保留原版Word版式时，使用当前业务中可访问的原文件，通过inspect_document_file及edit_document_file另存；本目录的历史.doc只作来源留存，工具暂不能编辑旧版.doc，不冒称已支持。

模板条款可按需要删改，未知值不自动套用默认值。至少核对买卖双方、产品与价款、质量验收、付款触发、交货及风险、违约、解除、争议解决与签署是否协调；多主体安排保留各角色及未签约第三方的界限。空白比例、期限、独家、信用证、Incoterms及其版本、适用法律和仲裁安排均须按事实明确，不能沿用上游外国法默认值。格式文本及合同约定不证明法定义务，引用法条仍先查内部库，再按缺项补查官方原文。

交付全文时，以一级标题写合同名称，二级标题写“第一条”等条款，三级标题按需使用；表格不超过五列，长货品信息可另作附件。保留合同编号、双方信息、附件和两列签署栏。不要把聊天说明、“法律分析”、来源核验日志放进合同；必要的待填位置保留在对应条款，稿外用一句话说明影响签署的缺项。

已有模板只需填写少量事实时，优先由文件工具保留其余条款，替换使用已读原文并核对expected_count。示例：

```json
{"filename":"茶叶采购合同-草稿.docx","format":"docx","template":"tea_purchase","replacements":[{"old_text":"甲方（买方）：[待补充]","new_text":"甲方（买方）：甲茶坊","expected_count":1}]}
```

此方式默认contract版式，未知处继续保留，不同时传content。需针对本次交易重新起草全文时可采用以下方式（content须使用完整正文）：

```json
{"filename":"茶叶采购合同-草稿.docx","format":"docx","layout":"contract","content":"# 茶叶采购合同\n合同编号：[待补充]\n\n甲方（买方）：……\n乙方（卖方）：……\n\n## 第一条　产品与价款\n……完整正文……"}
```

需要同内容PDF时另调用一次format="pdf"。contract版式采用A4、左右25毫米及上下22毫米页边距、居中标题、黑色条款标题、正文与表格分级字号、页码；Word增加重复表头与适合长度的表格行不跨页，PDF使用固定列宽与重复表头。此为茶渡版式约定，不宣称国家强制格式。文件生成与重开沿用原工具，无新增模型或审核步骤。正文与来源支持仍由当前Agent核对，文件结构检查不能证明法律内容准确。
