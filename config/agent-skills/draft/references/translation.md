# 法律翻译与双语文稿

吸收 LegalQuants legal-translation 的术语一致、法域差异与法律效果保留方法。按用户指定或上下文已明确的目标语言完成翻译；语言不明时只问目标语言，不额外要求访谈或双语律师先行确认才能交付工作译稿。

读取实际原稿和版本，保留条款编号、姓名、主体角色、金额、币种、期限、定义及交叉引用。may、shall、unless、subject to 等表达须结合句意保留许可、义务、例外和条件，不将有条件的要求翻成无条件义务。否定、责任限制和终止后存续逐处对照，原文含糊时保留其含糊并在稿外解释，不能借翻译替双方决定权利义务。

同一术语一致使用。没有对应法律制度的术语可保留原词并解释，未经请求不将一种法域制度改成另一法域的合同安排。原文引用的法律名称与条号保留，用户要求核对时先查内部库、缺项再查官方原件，未经核对不能补写成确定法律结论或擅自纠正原文。

单语或双语形式按要求交付，完整译稿在前，影响理解的术语选择、未读部分与疑义在稿外说明。法规自译文本明确其为辅助译文，不称官方译本。公证、宣誓或认证翻译需要相应资质与手续，说明本次交付未具备这些资格，不伪造认证、签字或资质。

用户要求可下载文件时复用文档工具，不需要文件时直接提供完整译文。未指定优先语言的双语合同不能擅加某种语言优先条款。翻译不自动改变适用法律，不将普通工作译稿描述为已经满足法院或监管提交要求。
