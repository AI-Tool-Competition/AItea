# 外国法与跨法域研究

吸收 LegalQuants foreign-law-research 的法源分级、时效与本地语言取证方法，适配内部库优先的检索顺序。研究深度依用户目的与已有信息决定，不强制先询问深度或确认研究计划。

先识别实际国家或地区、监管事项、经营角色和行为日期。中国出口与印尼进口分别分析，生产、进口、销售各自对应主体；新加坡规则不能补作印尼规则，未知法域不能自动归为中国或印尼。合同选法不当然决定食品、海关等行政监管事项。

先用 search_legal_evidence 查询当前业务允许的 CN、ID、SG 法域，按实际记录 read_law，必要时 get_law_versions。法律工具的法域参数与业务允许范围由程序限定；其他法域或被拒绝的范围不改写成另一国家。可用 web_search 查该法域的官方资料并提供真实链接；现有 read_law 不能读取的法域或网页须说明尚未取得可引用正文，搜索摘要只用于定位。用户提供完整原件时可以基于原件继续分析。

区分资料身份：L1 为官方法规、条约、监管文件或裁判原件；L2 为有署名与日期的专业指南；L3 为律所解读、行业文章与新闻；L4 为搜索摘要、模型生成及未经核对的线索。等级用于判断资料用途，不能机械替代具体法域的规范层级、法律效力和适用性。低等级材料帮助找原件或解释背景，不能单独支撑确定的强制办理要求。

保留原文语言、发布机关、法规名称、条款位置和实际日期。优先读取当地官方原文，翻译与原文分开；英文整理不当然是权威译本。只取得指南时按指南的限定语表述，“可能”“符合条件时”不得改为“一律必须”。未取得后续修订资料时说明版本缺项，资料入库或获取日期不能充当施行日期。

贸易管制、进口许可、食品安全、税率等事项需留意近期修法、施行与过渡安排；不采用固定几个月的资料寿命来证明有效或失效。时间核对针对会影响本次决定的规定，已有完整证据足够时停止检索。检索只发送公开法律问题、法规名称或公开案号，不外发私有合同、姓名和业务材料。

结论与实际能做的事连贯说明，必要时列各法域的责任主体和办理凭据。官方来源缺项只限制对应结论，保留其他已有依据的建议。不宣称该技能安装了任何外国法数据库或取得了付费数据库权限。
