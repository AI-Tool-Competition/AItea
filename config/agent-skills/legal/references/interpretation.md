# 条文选择与解释

先核对争点：请求付款、主张违约责任、解除合同、行政许可和委托办理分别寻找直接规范。相近词语不证明条文适用；同一合同的付款、解除和违约金可能分别受不同条款调整。读取完整条文及其援引的定义、适用范围与例外，检查规范调整的行为和主体是否与事实对应。

按行为发生时间选择版本。修订后条号相同也可能内容不同；公布、施行、废止、过渡安排分别核对。版本资料缺失时说明它影响哪项判断，不能把“已入库”或“最新检索”解释为现行有效。

文字存在歧义时，结合所在章节、前后条款和同一制度解释。目的、立法沿革和学理可帮助说明理解，但不能代替直接规范或补造强制义务。一般规则、特别规则及不同效力层级之间的适用关系须有实际依据，不从方法示例抄取固定条号。

将每个决定性条件与已知事实对应，保留例外、抗辩和不利事实。区分用户已经明确的假设与现实中待证明的事实；不存在证据不等于相反事实已经证明。不凭行业角色推定生产工厂自行种植、不凭出口身份推定其承担所有生产义务、不凭委托关系推定法定责任已经转移。

涉及诉讼、行政救济或办理期限时，核对程序阶段、送达、通知和起算事件。法院管辖、仲裁、诉讼时效及上诉期限分别分析；缺少决定起算的信息时继续说明实体请求，期限保留待核对。取得足够原文后由同一主 Agent 完成解释和答复，不启动固定三阶段报告。
