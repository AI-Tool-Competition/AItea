# 法律研究与命题核对

吸收 Legal-Agent-Skills 的检索与事实对应、LegalQuants 的 proposition-checking 和 adversarial-qc 的反证检查方法。用于需要研究或核对的事项；普通问答不生成独立研究档案或复核证书。

先明确用户要作的决定、适用法域、行为时间和决定结论的事实。按争议中的主体、行为、请求与规则要件检索内部库；已有证据复用。内库缺少材料或版本才补查外部官方来源。类案比较须实际读到裁判，比较事实、程序阶段、裁判理由与后续处理，不凭少数命中推定整个地区的裁判趋势。

优先找支撑用户所求法律效果的直接规则。检索命中的是另一种法律效果时，以请求所对应的法律术语定向补查，不能反复替换生活用语后沿用同一条不对应的规则。能否请求履行、是否违约、能否解除与赔偿范围分别有其适用条件；只有用户任务需要时才展开其他效果，不混用其前提。

每项需要核对的命题对应实际读过的条文、裁判或业务材料，保留来源编号、文件版本、条款或段落位置。核对原文是否涉及相同主体、条件、行为和法律效果，定义、例外及关联条款是否限制结论。法院引用的当事人意见、被否定的主张和个案裁量不得冒充普遍裁判规则。

需要逐项检查时可在本次上下文记录以下结果，不强制创建持久化对象：

| 结果 | 判断方法 |
| --- | --- |
| 支持 | 原文直接支持完整命题，适用条件相符 |
| 部分支持 | 原文支持其中一部分，原表述扩大范围或遗漏条件；给出缩小后的表述 |
| 不支持 | 已读相关材料未提供该命题的根据；不据此推断所有法源均无规定 |
| 与原文矛盾 | 相关原文有相反规定或判断，指出位置与差异 |
| 引文不准确 | 引用文字与原文不符，保留原条件后纠正 |
| 未能核对 | 原件不可读、定位缺失或资料不足；不凭模型记忆归入其他结果 |

在现有分析中检查最可能改变建议的不利规则、反例、相反证据，以及未给出的合同分工；找到会改变判断的缺口才定向补检。无需对每道题开展固定轮次检索、两个模型互审或等待人工审核。仍无法查明时，交付有支持的部分并说明具体缺项及其影响。

交付前随本次作答检查请求是否覆盖、法域与适用时间是否对应、事实是否来自材料、主体和条件是否保留、引用是否支持表述。来源存在不能证明解释正确，格式校验不能代替法律判断。用户只问一个问题时直接回答；要求研究报告或核对清单时再采用相应形式，不向茶商展示内部检查状态。
