# 新加坡法规和裁判引用核对

改编自 LegalQuants 的 sgcite（Yu Chou Teo）与 bart-statutory-reference-checker（Kevan Wee）。只吸收核对方法，未安装 sgcite 命令行、BART 私有后端、向量库或 Word 插件。

先核对实际法域及用户要求的行为日期。内部库优先：search_legal_evidence 查询 SG；read_law 读取返回的真实记录；get_law_versions 读取已有修改、施行、废止关系。只有内库未覆盖相关原文、版本或裁判时再用 web_search 找官方原件。SG 不在当前业务允许范围时保留程序限制，用公开资料查询交付可取得的内容，不将参数改为 CN 或 ID。

法规补查定位 Singapore Statutes Online（sso.agc.gov.sg）。核对法名、section/subsection、附属法规身份、修订施行日期及历史版本，废止信息还需结合保留和过渡规定。不能仅凭条号格式正确、语义近似或当前网页显示新文本就自动替换旧引文。

裁判补查定位新加坡法院与 eLitigation 的判决原文。分别核对公开中性引注、当事人、法院、日期、段落编号及逐字引文，区分多数意见、附带意见、不同意见和当事人陈述；案件真实存在不证明裁判支持本次论点。没有读到原文段落时只能说找到候选案件或链接，不能称段落和引文已经核对。

当前官方正文工具按法域与来源域名读取；eLitigation 的 elitigation.sg 不属于现有 gov.sg 来源范围，不能假装已通过 read_law 读取。可以提供实际检索返回的官方链接，使用已入库完整文本或用户提供的判决继续核对；无法取得原文时说明具体缺项。动态网页、验证码、未公开裁判或未解析 PDF 也可能限制读取，不把检索未命中称为案件虚构。

查询只发送公开法规名称、案号或中性引注，不上传私有文件或围绕案件的私人事实。已经读到原文的结果保留位置及来源，无法核对的引用保留原样并指出问题；不得因其中一项无法核对就清除其他已读结果，也不生成已经通过审查的证明。
