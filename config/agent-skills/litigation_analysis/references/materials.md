# 按材料核对

起诉材料：识别实际请求、金额构成、各请求依赖的事实和证据。核对合同、交付、验收、对账、付款与催告记录之间的对应，标明证据来源及用户代表方。没有提供的附件保持缺失，不能补写其内容。证据是否足够、是否可能受到质疑，与事实是否真实分别说明。

裁判材料：区分诉辩意见、法院查明、裁判理由和裁判主文。说明法院实际处理了哪些请求、支持多少、驳回什么及理由，核对本案争议与援引规范的关联。判决摘录不足时限定阅读范围，不将未读部分当成没有论述。

后续裁判：只有读到前后裁判才逐项比较请求、事实认定、理由和主文。新增材料标明何时提交、是否被法院采纳；程序结束、救济期限和执行状态没有材料时保持未知。再审、上诉与执行各有条件，不合并为同一项办理建议。

庭审记录：将当事人的陈述、自认、证据出示、质证意见与法庭处理分别定位。根据记录说明哪些内容有争议，未记载不等于没有发生。询问、调解意见或暂时评价不足以预测最终裁判。

交付只选用户需要的内容：解释判决时先说结果及履行影响；准备起诉时先说明请求和材料缺口；准备答辩时说明应回应的事实与证据。页码、金额、日期和逐字引文只使用实际读取的位置，不套用示例条号或预设期限。
