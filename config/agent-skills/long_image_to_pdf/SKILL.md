# 长截图转 PDF

用户要求整理长聊天截图、网页截图或其他长图为 PDF 时使用。先用 list_documents 确认当前业务图片的 document_id 和不可变 version；只有图片不明确或有多张需选择时追问。没有上传图片时说明需提供的文件，不猜本机文件位置，不下载任意网址。

调用 convert_long_image_to_pdf。默认每片 2000 像素高、相邻重叠 200 像素、每页两列两行，layout=grid 按行从左到右排列；layout=column 按列从上到下排列。用户可指定每页一至三列、一至四行和工具允许的切片参数。追求较大字号时减少每页切片数量，保留截图顺序与边缘内容。

工具仅在本地处理图片，不进行 OCR、不联系模型或外部服务。图片尺寸、切片数、PDF 页数、文件大小和运行时间由程序限制；损坏图片返回具体错误，不能以日志文字替代真实文件验证。原图保持原样，生成文件只作排版副本，不表示证据真实性、完整性或证明效力已经确认。

工具返回 pending_commit 时表示文件已生成、尚待本轮答复共同保存，不能声称已经下载或已正式入库。答复成功后程序追加实际 PDF 下载链接；失败或取消时不创建可见附件。不自行拼造网址、文件编号或页数。MCP 未提供转换工具时说明当前只有方法说明，不声称完成转换。生成文件不自动进入 OCR、法规检索或法律审核。
