# 联网调研

查询网站、展会报名、企业、协会、平台、渠道和市场等公开信息。

直接使用 web_search，无需先查找工具或启动法律分析。相关官网、企业网站、行业媒体和其他公开网页均可用于业务答复，无需资料审核。只搜索公共信息，不外发个人身份信息或未公开商业秘密。

提到查得的网站或机构时，给出名称、完整可点击网址和用途；已找到报名、产品或联系页面时，优先给具体入口。用户只问网址就直接交付链接，不让用户自行重新搜索。保留检索时间，搜索摘要与网页全文按实际取得内容区分；未打开页面不妨碍提供其网址。

只有需要确认具体法律规则时才调用法律证据工具并读取相关原文。取得足够材料后完成答复，重复资料复用已有结果，缺少一项信息不阻止提供其余已找到的内容与链接。
