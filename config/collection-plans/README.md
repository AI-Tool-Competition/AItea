## 条目结构

- `chapters` 保留五章结构；`items` 保留原项号，已移除的来源条目不复用编号。印尼 v17 启用 16 个当前可访问来源；v16 快照保留本次升额前的配置，v15 快照保留 UUD 1945 移除与央行切换前的范围，v14 保留旧央行来源，v13 保留已退役的政府采购与 RCEP 入口，v12 历史配置保留 ACFTA 入口，v11 保留原 29 项范围。央行适配器仅允许 `www.bi.go.id` 的法规门户：目录每页核验 10 条详情及官方总量，按相邻页串行提交同源 WebForms 表单；隐藏状态只在请求内存中使用，证据记录原页和请求体哈希，不保存隐藏值。详情页提取可见元数据，并区分正文候选、问答及附件；文件名不能单独证明文书身份。正文仅接受有效 PDF 签名。交通部法规和 Treaty Room 条约原件分别设置 300 MiB 单件上限；劳动部原件设置 128 MiB，万隆地方规范与司法总局实施文件仍为 128 MiB；这些来源的下载时限均为 900 秒，其他来源使用各自额度。
- `entries` 区分目录、详情、原件及参考用途。只有这些入口参与当前发现；`verbatim_requirements` 仅用于回查用户原始要求，其中保留的旧网址不代表当前可访问，也不是额外抓取种子。`reference` 示例不得自动作为执行入口。
- `scope_include`、`scope_exclude`、`steps`、`fields`、`version_rules`、`relation_rules`、`acceptance` 是从原要求整理的工作边界。`verbatim_requirements` 保留本项原始文字，供复核和修订时回查。
- `tags` 使用稳定的国家、条目、文种和主题标记，例如 `country:ID`、`checklist:ID-3.3`、`kind:case`、`topic:MA HUM`。标签不决定法律效力，也不能代替法规的国家隔离。
- `priority` 是执行顺序，不代表法律位阶或一二级资料等级。`limits` 描述业务范围，单批并发和队列上限由采集服务控制；达到单批上限不表示全量采集完成。

## 执行和核验边界

预置方案提供采集范围和可审查的发现入口。`adapter` 选择目录发现方式，不能证明某站当前可访问，也不能把 URL 匹配结果视为内容或法效审核通过。动态页面、登录、人机验证、访问限制、解析失败、附件缺失和无可用链接都应显示明确缺口。不得保存错误页、拒绝页、验证页或空框架冒充法律正文。

候选文件须核对文书身份、内容范围、原件、适用期间及法律状态后再作为依据。章号和法律效力不决定一级／二级：指定主资料为一级，其有原文证据的引用或关联资料为二级。`relation_rules` 只是待核映射要求，不能自动创建不存在的父资料或断定修订、失效。引用关系、法规生命周期关系、条约批准／实施关系须分别保留。

国家边界使用 `country:ID` 和 `country:SG`；计划标识和章节只用于该国家内的任务管理。新增国家应使用独立 `country` 和独立方案，并通过后端隔离规则限制目录、资料、关系和检索，不能仅靠来源标签混用法域。

目录发现、详情登记、原件取得、附件齐全、正文解析、范围审核、效力核验和索引分别验收。默认来源和法规状态均待核；全量目录不等于全量正文，更不等于全部已核有效法规。新版本追加保存，不能覆盖旧版；同一原件跨任务去重并保留各入口与来源关系。

## 印尼来源可达性与范围

v17 当前活动清单使用经项目代理核验的来源：UU、Perppu、PP、Perpres 使用 Setneg JDIH；常驻采集器按类型生成固定的只读 JSON POST 请求，并逐页验证记录总数和稳定 ID；地方条例和地方行政首长规章限万隆市 JDIH；中央部委法规限交通部 JDIH；宪法法院 PUU 仅保留两份已验证的官方判决原件，不代表目录全量。UUD 1945 的 MKRI 入口持续超时，MPR JDIH 与官方 PDF 在代理下返回 403，因此 1.1 从活动清单移除，完整定义保留在 v14 快照。央行目录已切换到 Bank Indonesia 官方法规门户，使用分页表单逐页发现 10 条记录、核对显示区间和官方总量，再采详情、元数据及可见 PDF 附件；旧 JDIH 入口保留在 v14。I-TIP Services 精确入口经代理复核发生重定向循环，已从活动抓取入口降为 `reference`；2026-10-13 已验证的 PDF/CSV 原件继续保留，但不代表后续更新完成。政府采购 JDIH 多个目录页连续连接超时，RCEP 秘书处域名无法解析、DFAT 与商务部入口连续超时，4.7 和 5.3 已从活动清单移除，旧定义保留在 v13 快照；ACFTA 仍是单独的覆盖缺口。BPK、最高法院相关目录、MKRI 判决目录及 KPPU 入口在此次代理实测中受限，因此对应来源暂不启用。后续若访问恢复，应重新验证目录、分页、详情和原件后再发布新版本。

现行来源数量、单批完成量和解析成功量都不代表全国范围完整。不可达范围作为缺口保留在章说明中；历史任务继续使用不可变版本，不因本次清单调整而改写。
