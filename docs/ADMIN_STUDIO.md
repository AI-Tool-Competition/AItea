# 配置后台

从办理工作台打开“管理后台”，或访问 `/tea/admin/workflow`。后台使用当前账号的配置与资料。

后台与办理界面共用 DeerFlow 的字体、明暗主题、颜色变量和基础控件。保持简洁商务样式：主要内容使用黑白灰，颜色只提示状态；页面顶部只保留配置选择和操作按钮，编辑栏覆盖在右侧，列表与画布始终使用完整工作区。

## 办理流程

“办理节点 → 任务 → 填写项”以多级列表铺满工作区。点击展开箭头查看子项，点击要编辑的项目展开右侧浮动编辑栏，不挤占列表或画布。点击编辑栏外、收起按钮或按 Esc 收起，未保存的内容会保留。新增、排序与删除都作用于草稿。手机上编辑栏从右侧展开，仍可点击外侧回到列表。侧栏使用轻量滑入、淡出过渡，开启减少动态效果时直接切换。

点击列表顶部的流程名称，修改基本信息和办理模式。节点设置中可以前往该节点的主动分析配置。必办任务的字段、材料与确认要求共同决定能否进入下一节点。

## 节点分析

`/tea/admin/analysis` 默认显示完整宽度的工作流画布。选择办理节点后，点击画布步骤展开右侧编辑栏，编辑名称、类型、要求与启用状态；点击编辑栏外可收起。使用前移、后移调整实际执行顺序。画布支持平移、缩放和显示完整流程，也可通过步骤选择框定位编辑项。

节点默认沿用统一分析流程。选择“单独配置”后只修改当前节点；选择“编辑默认”会影响所有沿用默认设置的节点。“流程设置”标签维护整体要求、输出语言与检索数量。

点击顶部“调试”后，右侧同一个浮动编辑栏切换为试运行；“编辑步骤”切回配置。样例、结果、对比和记录通过标签切换，画布保持完整宽度。关闭侧栏或切换后台页面保留本次输入与结果；刷新前应保存样例。

在“样例”填写测试问题、任务资料，选择检索资料和预期结果，再保存为可重复使用的样例。保存时固定所选资料的版本，避免资料库新增内容悄悄改变测试范围。默认选择当前共享资料库，也可限定具体资料或不检索资料。这里的资料选择仅控制检索范围，不替代实际业务的材料关联或人工确认。删除配置中的填写项后，可通过“移除旧输入”修复旧样例；草稿修订冲突会保留当前填写。

在画布选择步骤后，可进行四种操作：

- **试运行**：用当前配置从头运行。
- **运行到这里**：从头运行，完成所选步骤后暂停。
- **只试这一步**：复用有效的上游结果，仅执行所选步骤。
- **从这里继续**：复用有效的上游结果，从所选步骤运行到结束。

后两项需要已有运行记录。输入、上游配置、资料或执行环境变化后，过期的上游结果会被拒绝，需要从头运行。修改所选步骤自身的要求，可以单步重试。点击“停止”后保留已完成步骤；若停止记录尚未返回，可在历史记录中刷新后载入。

“结果”随执行展示步骤状态、耗时、实际输入输出、检查项和原文引用。预期结果与执行状态分开展示：执行完成不代表所有预期通过；尚未生成有效回答时，回答预期显示未评估。文字和检查项支持自动检查，表达质量等主观要求保留人工确认。原始数据按需展开，不展示内部思考。没有配置模型时明确显示规则演示，自由文本分析要求需要接入模型才会参与生成。

“对比”选择历史记录，查看修改前后的输入、配置、检查项、引用和回答。“记录”可载入旧结果、恢复测试输入，或用当前配置逐个运行当前节点的全部已保存样例；批量结果分别显示执行状态与预期检查，不自动决定发布。每个账号最多保存 100 个样例；历史保留最近 100 次运行，并受总计 64 MiB 的容量限制。调试与业务分析共用执行器，但不改变实际业务、任务或文稿。

## 保存与发布

“保存草稿”允许保留尚未填完的配置，两个编辑页面共用草稿。切换页面会保留未保存输入；关闭或刷新页面前仍应保存。

“更多配置操作”中提供校验、导入和导出。导入新的配置编号会建立独立草稿；保存后可从配置选择框重新打开。发布前自动校验，成功发布后，新业务读取新版本，已有业务保留原配置快照。

如果另一窗口已保存更新，当前页面会提示冲突并保留输入。先导出备份，再选择“读取已保存草稿”，核对合并后保存。

## 资料库

侧栏统一使用“资料库”入口，页内通过“资料 / 来源”切换。`/tea/admin/library` 按一级资料列出目录，可以搜索名称、筛选所属业务，并展开二级附件；`/tea/admin/sources` 保留为来源视图的直接链接。打开一级资料后查看结构化拆解、检索片段和原文位置；每页有界读取，超过一页时显示翻页按钮。

开发环境可点击“开发样例”在新标签页预览，保留原页面的填写；也可访问 `/tea/admin/library?sample=1`。内含两份主资料、两份关联文件及两个来源，支持搜索、正文片段、关联跳转和视图切换。样例仅保存在前端，不调用资料或来源接口，不写入数据库、不采集、不参与检索，也不代表真实法规。点击“退出样例”返回当前账号的资料；生产构建不提供该入口。

一级资料负责解析与检索；二级资料只保留原件。资料详情可添加二级附件、下载原件和维护审核信息。未审核、过期或被替代的法规不会作为有效依据。

办理界面进入已解锁节点时会自动分析当前资料。同一份资料重访复用结果，相关资料变化后重新分析；建议不代替人工确认和服务端核验。
