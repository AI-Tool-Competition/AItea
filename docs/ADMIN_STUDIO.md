# 配置后台

从办理工作台打开“管理后台”，或访问 `/tea/admin/workflow`。后台使用当前账号的配置与资料。

后台与办理界面共用 DeerFlow 的字体、明暗主题、颜色变量和基础控件。保持简洁商务样式：主要内容使用黑白灰，颜色只提示状态；页面顶部只保留配置选择和操作按钮，编辑栏覆盖在右侧，列表与画布始终使用完整工作区。

## 办理流程

“办理节点 → 任务 → 填写项”以多级列表铺满工作区。点击展开箭头查看子项，点击要编辑的项目展开右侧浮动编辑栏，不挤占列表或画布。点击编辑栏外、收起按钮或按 Esc 收起，未保存的内容会保留。新增、排序与删除都作用于草稿。手机上编辑栏从右侧展开，仍可点击外侧回到列表。侧栏使用轻量滑入、淡出过渡，开启减少动态效果时直接切换。

点击列表顶部的流程名称，修改基本信息和办理模式。节点设置中可以前往该节点的主动分析配置。必办任务的字段、材料与确认要求共同决定能否进入下一节点。

## 节点分析

`/tea/admin/analysis` 默认显示完整宽度的工作流画布。选择办理节点后，点击画布步骤展开右侧编辑栏，编辑名称、类型、要求与启用状态；点击编辑栏外可收起。使用前移、后移调整实际执行顺序。画布支持平移、缩放和显示完整流程，也可通过步骤选择框定位编辑项。

节点默认沿用统一分析流程。选择“单独配置”后只修改当前节点；选择“编辑默认”会影响所有沿用默认设置的节点。“流程设置”标签维护整体要求、输出语言与检索数量。

点击顶部“调试”打开抽屉，填写样例后运行整个节点，或运行到选中的步骤。结果包括实际步骤输入输出、缺项检查和原文引用。关闭抽屉保留本次样例与结果；更改配置后旧结果失效，需要重新运行。调试不会修改实际业务。没有配置模型时显示规则演示，自由文本分析要求需要接入模型才会参与生成。

## 保存与发布

“保存草稿”允许保留尚未填完的配置，两个编辑页面共用草稿。切换页面会保留未保存输入；关闭或刷新页面前仍应保存。

“更多配置操作”中提供校验、导入和导出。导入新的配置编号会建立独立草稿；保存后可从配置选择框重新打开。发布前自动校验，成功发布后，新业务读取新版本，已有业务保留原配置快照。

如果另一窗口已保存更新，当前页面会提示冲突并保留输入。先导出备份，再选择“读取已保存草稿”，核对合并后保存。

## 资料库

`/tea/admin/library` 按一级资料列出目录，可以搜索名称、筛选所属业务，并展开二级附件。打开一级资料后查看结构化拆解、检索片段和原文位置；每页有界读取，支持翻页。

一级资料负责解析与检索；二级资料只保留原件。资料详情可添加二级附件、下载原件和维护审核信息。未审核、过期或被替代的法规不会作为有效依据。

办理界面进入已解锁节点时会自动分析当前资料。同一份资料重访复用结果，相关资料变化后重新分析；建议不代替人工确认和服务端核验。
