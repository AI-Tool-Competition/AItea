# Agent 调度与记忆

节点会话使用模型驱动的工具循环：模型选择下一步，服务端验证并执行工具，将实际结果送回模型，直到形成答复或达到预算。适用入口为带 `conversation_id` 的节点聊天，包括引导会话。无生成密钥时仍显示演示助手。历史不带会话编号的接口、后台断点调试和独立法律分析保留已有协议与配置流程。

## 工具与组合技能

办理指导、资料核对、法律分析、文稿起草和节点交接均有独立工具，由模型结合问题与当前业务状态自主选择和组合。

| 工具 | 行为 |
| --- | --- |
| `guide_business` | 读取当前节点、任务字段、事实和进度，供办理建议使用 |
| `check_materials` | 调用既有服务端材料检查，不改变任务状态 |
| `analyze_legal` | 调用持久化法律分析服务，保留法域、证据、版本及复核规则 |
| `draft_document` | 接收完整 Markdown 文稿，整轮成功后与消息一起保存 |
| `get_handoff` | 读取前序节点、待复核事项和当前节点进度 |
| `list_documents` / `read_document` | 有界分页读取当前业务及允许资料库的文档；跨业务私有文档被拒绝 |
| `search_documents` / `search_legal_evidence` | 复用 RAGFlow 检索与现有适用性、审核、版本过滤 |
| `inspect_image` | 读取当前业务中指定不可变版本的原图或已有页面图，调用识图网关 |
| `web_search` | 实时查询公开网络，保留 HTTPS 来源链接、摘录和查询时间 |
| `recall_memory` / `remember_memory` | 检索来源可追溯的记忆；用户明确要求时暂存其原话 |
| `discover_tools` / `load_skill` | 查询登记能力与加载组合提示，不授予额外权限 |
| `update_plan` / `read_tool_result` | 调整内部执行计划；分页回查本轮工具收据而不重复外部请求 |

组合提示位于 `agent_skills.py`，包含“图片 + 资料核对”“联网 + 法律分析”“法律分析 + 文稿”。它们作为内部调度提示推荐操作方法与能力组合，不锁定调用顺序。聊天输入框只提供提问与资料上传，不展示能力菜单、法律分析开关或记忆管理入口。前端不主动读取工具目录或记忆列表，也不发送能力选择；兼容接口仍接受原有可选字段。新增工具需提供严格参数模型、描述、处理函数、并发属性和超时，并同步 SSE 工具名称契约及前端解析器；新增技能只引用已登记的工具。

聊天进度复用 Vercel AI Elements 的 `Task`、`TaskTrigger`、`TaskContent` 和 `TaskItem`。发送时展开准备区；当前工具或重试开始时展开该行，结束后完全隐藏正文，只保留名称、状态与用时。展开一行直接显示完整的有界执行片段，没有摘要重复或第二层“展开结果”。并行工作的行可以同时展开。正文增量、内部模型轮次或其他工具结束都不会重新切换用户手动收起的面板；真正的新工具或新尝试启动才恢复跟随。整轮完成、失败、停止时自动收起整个进度区，历史记录仍可手动查看。记忆、技能、计划、上下文压缩和法律分析子步骤继续隐藏。

Gemini 请求显式启用 `generationConfig.thinkingConfig.includeThoughts`，只把上游实际返回的 `delta.reasoning_content` 思考摘要送入对应执行行。摘要通过 `tool_delta` 增量更新，结束时保存在该调用的 `output_preview`，与正式回答分开；不显示签名或其他模型的私有推理，不用预设文字补造思考。摘要未返回时仅保留等待状态。RAG 和独立联网工具目前返回完整 JSON，因此展示真实运行状态与完成结果，不模拟逐字生成。

展开与收起采用实际内容高度的 220 毫秒过渡，减少动态效果模式关闭动画；流式消息与保存后的消息保持相同界面标识。首个可见文字增量立即发布，后续增量按浏览器帧合并，后台页最多等待 50 毫秒；状态边界立即冲刷待显示内容。正文关闭逐词淡入，使用 Streamdown 的流式解析和光标，不增加打字延时。模型工具轮次之间保留已输出的公开文字，并以空行衔接，最终保存同一份累计文字。输入草稿和用户主动滚离底部的位置继续保留。

工具返回时，服务端从送回模型的同一份结果逐字选取正文、核对项、图片观察、结论和来源，生成 `output_preview`。正文最多 4,000 字、8 项结果、整体 4 KiB，超限标记节选；增量文本最多 3,500 UTF-8 字节，后续以最终快照校准。网页与图片保留未审核说明，文稿在事务提交前保留待保存说明。内容按文本渲染，来源链接检查协议，不展示密钥或工具参数。完整收据仍留在服务端；聊天传输最多 32 MiB。

读取类工具只在连续、参数合法的批次内并发，最多 4 项；法律分析、暂存文稿、暂存记忆、加载工具和计划变更构成串行边界。模型收到的结果顺序与请求一致。注册表由服务端装配，模型不能选择账号、任意函数、文件路径或网络请求地址。

工具出错会返回可修正的参数错误或简短失败说明。未登记的工具不能执行。相同函数及参数最多请求两次，避免无进展循环；外部服务失败或结果未知后，本轮不会重复该外部能力。调用事实通过 `step.tools` 展示，密钥不进入 UI。

## 模型与外部能力

配置统一从实例私有环境加载，示例见根 `.env.example`。

| 设置 | 含义 |
| --- | --- |
| `AGENT_MODEL` | 对话调度模型，默认 `gemini-3.8-flash`；显式设置后法律分析生成也采用此模型 |
| `AGENT_BASE_URL` | 模型 Chat Completions 地址；空值继承 `LLM_BASE_URL` |
| `AGENT_API_KEY` | 模型及独立工具使用的后端密钥；空值继承 `LLM_API_KEY` |
| `AGENT_TOOLS_BASE_URL` | 搜索与识图网关；空值继承 Agent 地址，必须使用 HTTPS |

本实例采用用户指定的 [Aerisun 接入指南](https://aerisun.top/sub2api/api-guide.html)：模型请求发送到 `/chat/completions`，独立工具发送到 `/v1/tools/web_search` 和 `/v1/tools/image_recognition`。不自动补 `/v1` 到模型基础地址。Gemini 工具参数分片与可选签名元数据会保留；截断、拒绝、缺失结束标志、重复调用编号或畸形响应不能被当成完成结果。

识图结果只属于当前对话的未审核观察，不写回文件正文、解析状态或 RAG 索引；原件正文仍走 MinerU。原图最大 8 MB，仅接受 PNG、JPEG、WebP，页面图复用既有受限渲染。识图工具输入文档编号和版本，不接受模型给出的本地路径或任意图片 URL。联网结果只作为待审核线索，不能冒充已入库、已审核且适用的法规；RAGFlow 未配置或无合格索引时返回真实的未就绪/空结果。

## 执行边界与持久记录

- 每轮最多 12 次模型决策、40 个模型请求的业务工具调用、64 条执行记录、900 秒；每次模型请求最多 6,000 输出 token。
- SQLite 原子领取保证同一业务同时只有一轮智能会话；未过期的运行最多 4 个，跨进程也有效。唯一请求键同时绑定内容哈希，不允许同编号改内容。
- `agent_runs` 保存账号、业务、节点、会话、请求哈希、租约和公开过程；`agent_tool_receipts` 在执行前记录请求身份，执行后记录有界结果。密钥、私有推理、图片 base64 不作为过程参数落库。
- 取消或崩溃不提交暂存文稿/记忆。已完成工具的收据保留；未知的外部请求不会因旧租约失效而自动重发。相同消息编号可取回已完成答复；中断请求需明确重新发送。普通断线重试沿用原编号；明确不可重放、业务/法律依据变化或租约失效后，用户再次点击重试使用新编号重新计算。
- 文稿与用户记忆在消息事务中提交；提交前重验业务修订、法律分析快照及版本。模型不能自行审批、确认任务或处理跨账号材料。
- 底层生成、识图和搜索连接支持主动取消。已有同步资料检索在现有网络超时或下一检查点退出，不声称它支持即时终止远端计算。

## 记忆管理

三类信息分开使用：当前服务端业务事实、用户显式保存的偏好/笔记、带消息来源的历史讨论。模型无权把聊天内容升级为已确认事实。记忆检索、会话摘要与上下文整理在内部处理；显式笔记仍只在用户对话中明确要求记住时保存，不额外追加记忆管理提示。兼容管理接口保留账号/业务/节点权限以及编辑、删除的修订号检查；前台不展示管理界面。

用户记忆可限本会话或节点共享，最多每节点 200 条，每条 2,000 字。业务笔记绑定实际业务上下文指纹；事实、材料或任务变化会在内部标记待核对，普通聊天导致的修订号变化不会使笔记失效。回复偏好不因业务资料改变而过期。删除会清空该记忆正文并从检索中排除；历史聊天和依法需要保留的既有执行记录是独立记录。

每轮成功后生成最多 8,000 字的会话摘录摘要，保留问题、回答片段、消息来源和当时修订。摘要是可追溯摘录，不是新事实或模型臆测的结论。原消息不因摘要更新而删除；记忆工具可在更早的节点讨论中按问题检索，不限于最近 12 条聊天。

## 对话缓存

页面历史缓存按账号、业务、节点和会话共同隔离，只驻留当前标签页内存。最多 20 个会话、每会话最近 200 条消息、总计 8 MiB，30 分钟过期，并按最近访问顺序淘汰。切回会话立即显示缓存及未发送草稿，同时后台同步；分页和迟到响应按消息编号合并，保留较新的记录。退出登录清空缓存、草稿并取消读取/流式请求，旧响应不能重新写入。刷新页面后从服务端读取持久历史，不把私有消息写入浏览器持久存储。

模型侧使用按账号、业务、节点、会话隔离的稳定 `X-Session-Id` / `prompt_cache_key`；标识为不可逆散列，不含明文账号或密钥。登记工具的定义与顺序在各轮保持一致，工具可直接按需调用，技能提供组合指引；不因发现技能而改变请求前缀。

SQLite 结构版本 27 增加 `agent_conversation_context`，每会话只保存一份最多 200 KB 的最近成功模型上下文，包含公开消息、完整工具调用/返回和不透明签名。与最终消息在同一事务保存；失败、停止、冲突不更新。读取校验账号、业务、节点、会话、最后一条已保存消息，以及系统提示、工具定义、供应商、业务资料和记忆版本的指纹。命中后保留原前缀并追加当前上下文与问题，支持刷新及进程重启；版本不匹配、插入了其他消息或超过预算时回退到最近 200 条、最多 60 KB 的公开历史。模型上下文仅在后端读取，不返回页面，也不把旧证据当作当前审核结果。旧库采用增量建表，备份/恢复与盘点已支持版本 27。

按 [Aerisun 接口指南](https://aerisun.top/sub2api/api-guide.html) 请求流式用量，运行收据保存实际上报的输入、输出及缓存 token。服务端上下文复用不等于供应商计费缓存命中：`cached_tokens > 0` 才是命中，0 为未命中，缺失为未知，不补造命中率或费用下降。Gemini 隐式缓存的条件与最低 token 数以 [Google 官方缓存说明](https://ai.google.dev/gemini-api/docs/caching) 为准，不通过重复填充无用内容来制造命中。网页搜索结果不缓存，每次新调用实时检索。

长上下文先缩短旧工具正文，必要时移除已经配对完成的工具交换，保留当前用户问题、近期结果和被压缩工具的收据编号。`read_tool_result` 可按编号分页恢复结果，不需要重新发起搜索或识图。最终模型请求仍有 256 KiB 上限，单次上游响应有独立大小限制。
