# Agent 调度与记忆

节点会话使用模型驱动的工具循环：模型选择下一步，服务端验证并执行工具，将实际结果送回模型，直到形成答复或达到预算。适用入口为带 `conversation_id` 的节点聊天，包括引导会话。无生成密钥时仍显示演示助手。历史不带会话编号的接口、后台断点调试和独立法律分析保留已有协议与配置流程。

## 工具与组合技能

截图中的五项能力均有独立工具，菜单表示用户的能力偏好，不再按关键词选择整个固定流程。

| 工具 | 行为 |
| --- | --- |
| `guide_business` | 读取当前节点、任务字段、事实和进度，供办理建议使用 |
| `check_materials` | 调用既有服务端材料检查，不改变任务状态 |
| `analyze_legal` | 调用持久化法律分析服务，保留法域、证据、版本及复核规则 |
| `draft_document` | 接收完整 Markdown 文稿，整轮成功后与消息一起保存 |
| `get_handoff` | 读取前序节点、待复核事项和当前节点进度 |
| `list_documents` / `read_document` | 有界分页读取当前业务及允许资料库的文档；跨业务私有文档被拒绝 |
| `search_documents` / `search_legal_evidence` | 复用 RAGFlow 检索与现有适用性、审核、版本过滤 |
| `inspect_image` | 读取当前业务中指定不可变版本的原图或已有页面图，调用识图网关 |
| `web_search` | 实时查询公开网络，保留 HTTPS 来源链接、摘录和查询时间 |
| `recall_memory` / `remember_memory` | 检索来源可追溯的记忆；用户明确要求时暂存其原话 |
| `discover_tools` / `load_skill` | 发现延迟加载的工具，加载组合提示，不授予额外权限 |
| `update_plan` / `read_tool_result` | 调整公开操作计划；分页回查本轮工具收据而不重复外部请求 |

组合提示位于 `agent_skills.py`，包含“图片 + 资料核对”“联网 + 法律分析”“法律分析 + 文稿”。它们推荐操作方法与能力组合，不锁定调用顺序。前端打开工具菜单时读取服务端目录。新增工具需提供严格参数模型、描述、处理函数、并发属性和超时，并同步 SSE 工具名称契约及前端解析器；新增技能只引用已登记的工具。

读取类工具只在连续、参数合法的批次内并发，最多 4 项；法律分析、暂存文稿、暂存记忆、加载工具和计划变更构成串行边界。模型收到的结果顺序与请求一致。注册表由服务端装配，模型不能选择账号、任意函数、文件路径或网络请求地址。

工具出错会返回可修正的参数错误或简短失败说明。未登记或尚未加载的工具不能执行。相同函数及参数最多请求两次，避免无进展循环；外部服务失败或结果未知后，本轮不会重复该外部能力。调用事实通过现有 `step.tools` 展示，思考内容与密钥不进入 UI。

## 模型与外部能力

配置统一从实例私有环境加载，示例见根 `.env.example`。

| 设置 | 含义 |
| --- | --- |
| `AGENT_MODEL` | 对话调度模型，默认 `gemini-3.8-flash`；显式设置后法律分析生成也采用此模型 |
| `AGENT_BASE_URL` | 模型 Chat Completions 地址；空值继承 `LLM_BASE_URL` |
| `AGENT_API_KEY` | 模型及独立工具使用的后端密钥；空值继承 `LLM_API_KEY` |
| `AGENT_TOOLS_BASE_URL` | 搜索与识图网关；空值继承 Agent 地址，必须使用 HTTPS |

本实例采用用户指定的 [Aerisun 接入指南](https://aerisun.top/sub2api/api-guide.html)：模型请求发送到 `/chat/completions`，独立工具发送到 `/v1/tools/web_search` 和 `/v1/tools/image_recognition`。不自动补 `/v1` 到模型基础地址。Gemini 工具参数分片与可选签名元数据会保留；截断、拒绝、缺失结束标志、重复调用编号或畸形响应不能被当成完成结果。

识图结果只属于当前对话的未审核观察，不写回文件正文、解析状态或 RAG 索引；原件正文仍走 MinerU。原图最大 8 MB，仅接受 PNG、JPEG、WebP，页面图复用既有受限渲染。识图工具输入文档编号和版本，不接受模型给出的本地路径或任意图片 URL。联网结果只作为待审核线索，不能冒充已入库、已审核且适用的法规；RAGFlow 未配置或无合格索引时返回真实的未就绪/空结果。

## 执行边界与持久记录

- 每轮最多 12 次模型决策、40 个模型请求的业务工具调用、64 条执行记录、900 秒；每次模型请求最多 6,000 输出 token。
- SQLite 原子领取保证同一业务同时只有一轮智能会话；未过期的运行最多 4 个，跨进程也有效。唯一请求键同时绑定内容哈希，不允许同编号改内容。
- `agent_runs` 保存账号、业务、节点、会话、请求哈希、租约和公开过程；`agent_tool_receipts` 在执行前记录请求身份，执行后记录有界结果。密钥、思考内容、图片 base64 不作为过程参数落库。
- 取消或崩溃不提交暂存文稿/记忆。已完成工具的收据保留；未知的外部请求不会因旧租约失效而自动重发。相同消息编号可取回已完成答复；中断请求需明确重新发送。普通断线重试沿用原编号；明确不可重放、业务/法律依据变化或租约失效后，用户再次点击重试使用新编号重新计算。
- 文稿与用户记忆在消息事务中提交；提交前重验业务修订、法律分析快照及版本。模型不能自行审批、确认任务或处理跨账号材料。
- 底层生成、识图和搜索连接支持主动取消。已有同步资料检索在现有网络超时或下一检查点退出，不声称它支持即时终止远端计算。

## 记忆管理

三类信息分开使用：当前服务端业务事实、用户显式保存的偏好/笔记、带消息来源的历史讨论。模型无权把聊天内容升级为已确认事实。用户可在“记忆”窗口新增、编辑、删除；编辑和删除使用修订号，冲突保留输入。未保存编辑按账号、业务、节点、会话保留在页面内存，退出账号清理。

用户记忆可限本会话或节点共享，最多每节点 200 条，每条 2,000 字。业务笔记绑定实际业务上下文指纹；事实、材料或任务变化会显示待核对，普通聊天导致的修订号变化不会使笔记失效。回复偏好不因业务资料改变而过期。删除会清空该记忆正文并从检索中排除；历史聊天和依法需要保留的既有执行记录是独立记录，界面明确说明删除范围。

每轮成功后生成最多 8,000 字的会话摘录摘要，保留问题、回答片段、消息来源和当时修订。摘要是可追溯摘录，不是新事实或模型臆测的结论。原消息不因摘要更新而删除；记忆工具可在更早的节点讨论中按问题检索，不限于最近 12 条聊天。

长上下文先缩短旧工具正文，必要时移除已经配对完成的工具交换，保留当前用户问题、近期结果和被压缩工具的收据编号。`read_tool_result` 可按编号分页恢复结果，不需要重新发起搜索或识图。最终模型请求仍有 256 KiB 上限，单次上游响应有独立大小限制。

## 结构升级与兼容性

数据库结构版本 24 增加运行、收据、显式记忆和会话摘要表；版本 25 为记忆与摘要增加业务上下文指纹。升级入口为 `shared/infrastructure/persistence/database.py`，已有业务、原件、聊天与法律分析均保留。尚无指纹的旧笔记按待核对处理。新增接口和 SSE 工具名称见 [接口契约](API_CONTRACT.md)。不改变历史消息幂等哈希或将参考包作为运行依赖。

实例备份校验识别版本 25，并按实际已应用的迁移检查对应结构。恢复保留记忆、会话摘要与工具收据，仅将旧进程仍在运行的 Agent 租约标记为中断，避免恢复后重复未知外部请求；历史共享法规迁移仍保留原有云端证据保护。

## 验证记录

2026-10-26 的独立接口实测验证了 Gemini 工具请求与回传续答、WTO 官方来源搜索、合成标签 `GREEN TEA - NET 250 g` 识别。第二轮隔离业务实测中，“指导 + 材料 + 交接”“文稿 + 显式记忆”“图片 + 联网 + RAG 未就绪反馈”三组场景的工具均成功返回；分别约 12、19、20 秒。实测使用隔离数据库和合成资料，没有修改真实用户业务。

法律分析单独实测发现 Gemini 曾生成越界的事实编号。修复向模型提供每个争点的可用事实/引用编号，并在原有一次结构修复预算内返回具体校验反馈；服务端门禁未放宽。复测约 54 秒完成，返回依据不足的待复核结果，没有将无审核证据解释为条件已满足。相关模型适配、法律工作区、调度与传输回归共 96 项通过。

桌面 1440×900 和手机 390×844 浏览器验收使用隔离业务实测导出的合成响应，完成 7 项菜单能力、组合选择、记忆新增/编辑/删除、冲突保留输入及刷新版本后保存检查；没有页面异常或水平溢出。浏览器环境使用临时中文字体并关闭开发热更新连接，未修改业务数据或全局字体。

最终工作树检查执行 `make check`（指定本任务独立的 `PYTEST_BASETEMP`，避免并行检查清理同一临时目录）：2,462 项后端测试、239 项前端交互测试及类型检查通过。`make build`、本次 Python 格式和静态检查、前端 Prettier/ESLint 以及文档相对链接检查通过。开发服务恢复后健康检查正常，工具目录和记忆接口已出现在运行中的 OpenAPI 契约。

普通回归使用受控供应商替身，覆盖并发顺序、非法参数、越权、重复请求、取消、未知结果、输入预算、旧库升级、记忆冲突和前端错误恢复。实测中的 RAG 场景刻意关闭 RAGFlow，验证未就绪反馈；它不证明当前生产资料的索引覆盖率或法律有效性。生产容量、长时间多实例压力和实际法律结论质量须按对应部署范围另行验收。
