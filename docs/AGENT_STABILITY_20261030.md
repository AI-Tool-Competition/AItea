## 保留的改动

模型流增加独立无进展截止时间。空帧和心跳不能持续延长等待；无正文、无工具请求片段时的流停滞可在原预算内重试一次，已有正文或残缺工具请求不重放。连接等待有上限；完整结束且没有残缺尾帧的兼容流不强制要求冗余结束哨兵。已有生成额度、一次截断续写和部分正文交付继续复用。

文件生成后主模型失败时，重新打开检查通过的文件可以通过程序说明与真实下载链接部分交付，继续检查归属、源版本和事务；取消不提交文件。文件操作支持新建Word、PDF、Excel、PowerPoint和文本文件，以及受限的定点编辑；原件保留。技能入口、资源与工具按需加载，来源和许可见 [说明](../config/agent-skills/NOTICE.md)。

实际取得的网页URL、法规名称和具体条号可与引用卡关联；同一法规页面不会因此附上全部候选条款。法规索引内部版本以 `index_snapshot` 提供，真实公布、施行与修订信息保留，历史引用恢复原不可变版本。此关联仅处理显示和追溯，不能证明模型对条文的解释正确。

公开业务网页可直接搜索并给出可点击网址。常用只读网络工具对明确暂时性错误最多尝试两次，未知读取结果与业务写入不因此重复。业务卡保留真实原话来源；有字段因无来源或冲突未写入时，记录部分完成并列出字段。同轮实际纠正可消除缺项，不自动删词或补造字段值。

曾试验在业务卡字段未写入时强制增加一次工具纠正。三次真实运行均产生额外无效调用，已撤去该安排。普通问答保持按需调用，不增加固定审核模型或业务卡纠正阶段。
