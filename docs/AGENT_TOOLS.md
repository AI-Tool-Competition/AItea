# Agent 工具执行与流式过程

## 实际调用边界

`app/contexts/conversation/application/tool_runtime.py` 为现有工作流提供四个固定工具。调用方绑定已鉴权的账号、业务、所选资料和版本，模型输入不能指定账号或注册可执行函数。材料检查与法律门禁继续通过现有业务服务执行。

| 工具 | 输入 | 返回与权限边界 |
| --- | --- | --- |
| `search_documents` | 查询、国家、数量、可选资料编号 | 复用 `Service.search` 的归属和资料范围过滤，返回真实片段 |
| `check_materials` | 当前任务编号列表 | 对调用方持有的任务快照执行服务端检查，返回缺项与冲突 |
| `search_legal_evidence` | 查询、允许法域、数量、可选资料编号 | 复用 `LegalService.search`，校验引用结构、国家与所选资料范围 |
| `generate_guidance` | 输出 token 上限、是否流式 | 调用配置的模型；完整正文返回后才记为完成 |

工具输入采用 Pydantic 严格校验，拒绝额外字段与隐式类型转换。检索每次最多 20 项；所选资料最多 200 个；生成最多 8000 个输出 token。工具名称、用途与输入模型集中登记，增加工具时应复用业务服务并明确是否产生写入。

## 失败、预算与取消

- 一轮执行最多 128 次工具调用，最长 15 分钟；每次调用共享 45 秒预算，包含重试等待。耗时由单调时钟计算。
- 仅连接建立失败与 HTTP 429、502、503、504 可以自动重试，最多两次。退避加入少量随机延迟；可解析的短 `Retry-After` 被尊重，长等待直接交由用户稍后重试。
- 权限、参数、结构错误及读写超时不自动重试。模型一旦产生正文片段，即使后续断线也不自动重发，避免重复内容与隐含的重复费用。
- 法律结构化输出最多修复一次结构或引用编号。传输错误由工具执行层处理，法律引擎不会再叠加一层通用重试。
- JSON 与 SSE 模型响应均使用可取消的异步连接和总超时。等待首字节期间也可以停止。同步本地检索在检查点响应取消；这不等于强制终止任意 Python 函数。
- 保留现有模型并发上限 4、聊天并发限制和有界 SSE 队列。模型返回最多 1 MiB、正文最多 20000 字符、请求最多 256 KiB。超限会明确失败。
- SSE 按完整事件解析，支持跨块 UTF-8、CRLF 和多行 `data:`。没有 `[DONE]`、明确的 `length`/`content_filter` 结束、意外的工具请求、拒绝或空正文都不能变成成功回复。
- 工具错误只公开分类和简短处理提示，日志不记录密钥、原始提示或模型正文。未完成聊天不写入最终消息；断点继续使用已有持久化与版本核验。

## 有序进度和历史

继续使用 `step` SSE 事件，每个事件是该步骤的完整公开快照，新增可选 `run_id`、`sequence`、`tools`。工具开始、等待重试、再次执行、完成、失败会立即发布步骤快照。每次逻辑调用只有一个工具编号，重试更新 `attempt`，不新增重复卡片。

前端按步骤首次出现的位置替换快照，同一运行中过时或重复的序号不会回退状态。工具按照调用顺序展示；停止或断线时关闭未完成状态，已经完成的结果保留。持久化消息和检查点使用现有 trace JSON 保存相同记录，不新增数据库表。旧记录没有工具字段时继续按原有步骤展示。

界面组合仓库已有 AI Elements `ChainOfThought`、`Task`、`TaskContent` 与 `TaskItem`。展示执行事实、结果摘要、耗时和重试次数。调用编号、原始参数、模型内部思考均不是默认界面内容。可展开记录支持键盘操作、窄屏换行和减少动态效果偏好。

## 缓存

继续使用已配置的 `deepseek-v4.1-flash` 与 Aerisun 自动前缀缓存。执行编号、耗时和重试状态不注入模型提示。重试沿用相同请求内容，稳定的系统指导和业务上下文继续排在变化的消息前；usage 中的缓存命中等字段继续记录。法律工作流适配层同时传递原有缓存键与业务上下文。

检索结果和工具输出不增加跨请求缓存，防止把旧资料、权限或审核状态当作当前证据。现有检查点恢复仍重新核对资料指纹。实际提示缓存命中取决于供应商响应，不能由本地执行记录推断。

### 2026-10-19 运行样例

通过实际配置的 Aerisun `deepseek-v4.1-flash` 连续发送两次相同的合成请求，第二次返回 `cached_tokens=1664`、`prompt_tokens=1677`；端到端耗时从 7.17 秒降至 1.35 秒。第一次未返回缓存计数，不能记为零命中。这是该样例的观测值，不代表所有业务输入或负载下的延迟、费用与命中率。后续真实界面对话曾遇到 HTTP 429，界面正确展示失败和重试入口。

浏览器在 1440 × 1000 与 390 × 844 视口检查工具记录、窄屏排版及刷新恢复。慢速输出、503 后一次重试、等待首字节期间停止使用明确标注的本地模拟模型完成；观察到同一工具编号依次更新状态，停止后服务端连接关闭。模拟结果只存放在独立验收工作树的临时业务数据中。
