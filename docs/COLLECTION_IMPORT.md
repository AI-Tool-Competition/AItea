# 把服务器采集成果加入应用总库

服务器采集目录中的数据库和账号各自独立。应用默认使用当前工作树的 `data/tea.sqlite3`，不会自动扫描 `data/campaigns/`。采集任务创建的体验账号没有可供用户选择的登录入口。原件、正文和真实向量已经采集成功，也不等于当前应用账号可以访问这些资料。

`scripts/import_collected_resources.py` 提供显式的服务器导入入口，底层模块为 `app.collection_import`。它只向已存在的目标归属转移指定来源账号的公共法律资料，不复制用户、会话、登录凭据或业务数据，不切换运行中应用的数据目录。系统总库的外层接线负责创建没有登录凭据、没有会话的内部归属，并显式准入公共法源；本工具不创建这种归属，也不把任意体验账号当作系统总库。通用导入仍可用于有明确授权的既有私人账号，私人资料保持账号边界。

从仓库根目录预检：

```bash
uv run --project backend --locked python scripts/import_collected_resources.py \
  --source-dir data/campaigns/<采集目录> --source-owner <采集账号ID> \
  --target-dir data --target-owner <系统总库已创建的内部归属ID>
```

默认只读。预检显示原件、完整正文、可以复用的向量、已校验账号 CAS 原件和关系数量，以及阻塞原因；不会初始化目标目录、创建归属、发布法律资料或调用模型。目标归属不存在时明确显示 `target_owner_not_found`。由已获授权的系统总库接线指定目标后，在同一命令追加 `--apply` 执行。源新增同版本解析检查点时，必须显式追加 `--refresh`；目标正文、元数据、用途分级已变化或存在活动处理租约时拒绝覆盖。

目标为系统总库时，预检逐件检查官方来源、国家及无业务归属；主文件和普通附件都必须通过。出现 `system_source_required` 时在复制任何 CAS 文件或初始化目标服务之前拒绝执行，不能先把私人或非官方原件转存到公共归属再拒绝入库。

显式 `--refresh` 会在来源检查点相同的情况下仍重新应用来源映射，可用于修复导入工具生成的派生路径；无活动租约、目标保护摘要和来源元数据/用途一致性条件仍必须通过。不带该选项的同快照请求继续保持幂等；刷新不创建原件新版本，也不覆写已修改或正在处理的目标资料。二次映射优先保留已经校验的目标 CAS 地址，不能把 PNG 路径按其父 PDF 的摘要替换。

首版只导入每个法规家族唯一的版本 1。存在多版本家族时预检显示 `unsupported_multiversion_family`，执行被拒绝，避免重导 A→B→A 时错误地产生新版本。源数据库使用只读事务快照；允许源任务继续处理，导入范围只代表预检所记时间的已保存检查点。普通关联附件仍只保存原件，不解析正文、不创建处理任务或向量。

所有原件和识别图片从源账号 CAS 校验摘要后转存目标账号 CAS。正文保留完整性和待核页；用途分类、法律资料类别、草稿状态和适用日期保留，不能变成普通已发布业务资料。固定版本关系使用新的目标资料标识；关系 registry、双端页面证据与派生映射保存在目标账号 CAS，保留原始资料标识、版本、摘要及派生映射原摘要，避免继续指向另一采集账号或旧服务器目录。同账号 OCR 复用证明不能跨账号宣称，首版拒绝包含这类证明的来源。

只复用完整主资料的真实索引向量。源向量必须与当前配置指纹、实际分块输入、维度、有限值和单位长度全部匹配；目标未配置同一 embedding 时不导入向量，保留待建索引状态。工具可以继承当前进程模型配置，也可用 `--models-env <私有配置文件>` 加载既有采集配置，不输出密钥、不调用模型。显式刷新时配置不匹配会清除本工具先前导入的向量，避免旧向量被标为当前完成。二级资料保留文本和关系但不导入向量。事务失败回滚资料、分类、关系和索引；已发布的不可变 CAS 文件可能保留为未引用原件，不删除其他数据。

导入后，由应用总库接线提供原件、正文和版本关系的只读访问；通用工具本身不扩大任何用户的读取权限。向量可以提前准备，正式 RAG 仍要求完整正文、一级用途、国家和版本选择以及法律审核。资料保持草稿，因此导入后不会自动出现在回答引用中；通过既有或系统库限定的审核流程核定来源和日期后，才进入相应国家和业务的检索范围。使用同一 embedding 配置才能继续使用已导入的真实向量；没有配置时显示词项检索。
