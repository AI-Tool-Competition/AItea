# 国别法律资料库

国别资料包由 `CountryPacks` 读取，供法律 Agent、独立法律分析和后台法律引擎共用。它使用独立的只读 SQLite 索引，保留交付包的原件、条款、目录与来源记录。已有 RAGFlow 资料服务继续处理普通上传和系统法规；国别包的词项或文件级向量命中不会被标记为 RAGFlow 检索结果。

## 数据位置与检索

从仓库根执行 `make instance-paths` 确认当前实例的 `data` 和配置位置。国别资料位于该目录的 `legal-library/`：

| 相对位置 | 内容 |
| --- | --- |
| `index.sqlite3` | 条款与正文记录、FTS5 词项索引、国别计数及来源指纹 |
| `vectors.sqlite3` | 与来源指纹和模型配置绑定的文件概况向量 |
| `clause-vectors.sqlite3` | 独立的正文条款向量及原文字符位置，支持分批保存与继续生成 |
| `source-packs/CN/茶渡中国法律资料/` | 中国资料原件、JSONL 数据及核对记录 |
| `source-packs/CN/import-report.json` | 中国包导入报告与压缩包哈希 |
| `web-evidence/` | 有界官方补检取得的页面正文、取得时间及哈希 |

官方页面正文保存后，可按国家及查询词再次检索；仅复用取得时间在24小时内且正文哈希一致的快照，保留完整条款或章节、原链接及取得时间。该缓存保存公开原文，不保存预制答案，也不证明规范仍然有效。过期快照保留用于追溯，不能抑制当前补检。官方搜索目录只用于定位，目录编号不作为法条。特定监管机构或法名的缺口不能由一般法律正文中的偶然提及填补。

本次功能工作树的 `data/legal-library` 已连接到团队仓库 `data/legal-library`，普通检索以 SQLite 只读方式访问共享公共资料。工作树的业务数据库和私有配置仍独立创建。初次挂载核验已命中并完整读取《民法典》第 579 条，外部调用次数为零，记录见 `.dev/final-plan-acceptance/worktree-library.json`。2026年10月28日后续已在独立测试实例启动服务，完成四题真实问答，见[完整实测记录](LEGAL_USER_TEST_20261028.md)。

检索先确定法域，结合精确法名与条号、词项召回及可用的文件级向量。向量来源、模型或维度不匹配时返回对应状态并使用真实词项结果。命中模式为 `local_pack` 或 `local_pack_vector`；没有包时沿用现有资料检索。文件向量用于选择候选文件，不能证明每个条款已经单独向量化。

条款检索对已提交的正文向量计算余弦相似度。模型、来源和分段规则匹配且已有完成记录时，部分索引也可补充候选，保留 `partial` 状态，并继续文件级语义及词项检索。尚未保存向量的记录不进入计算；部分索引不参与全库排名融合，避免向量化先后次序影响未索引条款的排序。索引全量完成后才融合条款语义与词项排名，精确法名及条号优先。模型或来源不匹配时保留原有回退，文件向量也不可用时使用词项检索。响应中的 `semantic_granularity`、`semantic_status` 和 `clause_semantic_status` 分别记录实际粒度与状态，不将部分索引标记为完整就绪。相关实验与局限见[法律检索研究记录](LEGAL_RETRIEVAL_RESEARCH_20261029.md)。

法名检索包含同名修改决定及施行、过渡条款，明确条号仍保留这些版本证据。中国目录中的公布、施行和终止日期及明确替代关系参与候选排序，原件哈希不匹配时不沿用目录日期。新加坡《食品条例》等中文法名映射到原文法名，PDF分段标题为空时通过已记录的文献标题定位正文。目录和导航文字不优先于实质条文。

中国规章候选按保存的原文引用补充上位法及修改决定，最多两轮、每轮最多八个名称；法名未完整出现时，通过规范标题与查询的连续词句关联相关程序。相关的取消、废止或修法实施说明也可作为解释资料进入候选，保留来源身份，不预设法律结论。新增关联候选占用有界额度，显式条号、适用时间和原文完整性规则继续执行。进口或出口查询按名称之外的行为判断方向，再比较正文；共同条款保留，明确指定的条号优先。

每项检索明确国家时，仅查询该法域；多项查询交替提供候选，再平衡所需法域。审计记录区分召回、进入模型、因预算排除和最终采用的资料。新加坡官方文本、韩国法制处收录文本、非官方转载与中文整理保留不同来源身份；`laws.sg` 转载只作定位线索，不能单独支持强制义务。内库仅命中明确不适用于问题时点的旧版且未限制文件范围时，可启动一次有界官方补检。

至少含 30 字符的正文按最多 1,800 字符、相邻 200 字符重叠分段，标题与条号提供上下文；原文与中文整理分别建立向量，排除标题、导航、链接及无法定位的记录。较短正文仍保留全文与精确条号检索。每次成功的外部批次立即保存，后续批次失败时仍保留已完成结果。相同输入只生成一次向量，国别、记录编号、原件哈希和字符位置分别保留；返回法律依据时继续读取完整原始记录，不把分段文本授予现行效力状态。查询按 256 条向量分批计算，避免将全库向量同时载入内存。

新加坡HTML正文按已保存的小节标题补读相邻同节段落，保留各原始记录编号。例如SFA进口页面的一般许可规则、食品分类与加工食品注册要求会一并进入分析，避免只读取总则。小节整体不超过5,000字符时才合并；超过预算保留原始记录，不裁掉例外后冒充全文。相同文献、版本、原始记录集合与正文的上下文仅发送一次；不同条文即使文字相同，仍保留各自定位。引用的 `locator.context_record_ids` 记录组成小节的原始记录。

表格行也参与同节补读，以保留相邻业务分类和许可例外；小节超过5,000字符时，只选择命中行及前后相邻完整记录，合计仍超出预算则保留原行，不截断表格行。原文展示和哈希包含实际合并的完整记录。

中国PDF目录标题若被误提取为条文或修订页眉，仅在原件哈希一致、首条保存正文含完整规范标题时采用该标题，并保留原目录标题及标题证据记录。不修改交付原件、索引正文、来源哈希或已生成向量。

引用保留 `document_id`、不可变 `document_version`、`chunk_id`、原件哈希、条号或正文单元编号。`metadata.source_record_id` 可以交给 `read_law` 读取完整记录。中文整理与外文原文分别标识；检索节选会标记 `context_complete=false`，分析前尝试补读完整记录。无法补全、无法定位或整条超过 5,000 字的记录不会作为完整法律依据。原件、整理文本和日期信息都不自动授予审核或现行效力状态。

## 导入与恢复

`scripts/import_china_pack.py` 接受原始交付 ZIP，验证归档名称、文件大小、SHA256 和索引完整性，不执行交付包中的代码。导入需要已有国别索引，会在事务内替换中国记录，保留其他国家记录；相同来源与内容再次导入时不重复更新。以下命令用于明确选择的新实例或停写后的目标实例，不能在活跃服务旁直接替换数据：

```bash
uv run --project backend --locked python scripts/import_china_pack.py \
  '/绝对位置/茶渡中国法律资料_交付包_20261028.zip' \
  --data-dir '/目标实例/data'
```

导入报告记录索引备份位置。恢复时停止所属实例写入者，按 [实例管理](INSTANCE_MANAGEMENT.md) 保留现有数据，再从同一备份恢复索引、来源包和相配的向量数据。仅恢复某个 SQLite 文件可能使来源指纹或引用版本不匹配；恢复后需核对国家计数、指纹、数据库完整性及原件读取。本轮未执行回滚、重建或实例切换。

`scripts/index_country_vectors.py --data-dir DATA` 使用已配置的真实 embedding 服务生成缺失的文件概况向量，支持校验后复用既有向量；该操作包含外部请求，应独立安排和记录。导入核验阶段只检查已有文件版本向量；后续真实问答已使用该服务生成查询向量，正文向量也已开始分批生成。

使用 `scripts/index_country_clauses.py --data-dir DATA --prepare-only` 建立条款清单；去掉 `--prepare-only` 后生成缺失向量，再次执行同一命令会复用匹配的已保存批次。`--max-batches N` 可用于小批量吞吐检查。来源指纹、模型或分段规则变化时拒绝覆盖旧索引。索引写入使用独立进程锁；磁盘空间不足时停止外部请求并保留检查点。跨进程配额通过既有 `EMBEDDING_ADMISSION_PATH` 共用，交互查询继续拥有优先级。调用模型、维度和配额沿用实例的现有配置，不另设密钥或关闭 TLS 校验。

普通问答与官方补检规则见 [法律 Agent](LEGAL_AGENT.md)，接口及权限见 [API_CONTRACT.md](API_CONTRACT.md)。
