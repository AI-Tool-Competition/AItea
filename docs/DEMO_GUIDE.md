# 五分钟体验

1. 打开工作台，选择“进入演示工作台”。新体验账号建立六堡茶印尼线上业务；新建业务可选择印尼／新加坡 × 线上／线下四条路线。
2. 在当前业务上传本批次的产品和主体材料，用途选择“主文件”。原文会保存，解析成功后可以用于本次业务的检索和核验。体验时使用明确标注的测试材料，不将演练记录当作实际办理凭证。
3. 展开流程，打开“建立业务路线卡”，填写责任人、产品范围、客户类型、交付方式、真实主体与核验依据，保存“等待外部”等当前结果。提交核验时，尚未完成的结果会保留缺项，下一阶段继续锁定。
4. 实际材料与结果核对完成后，选择“已核验完成”，关联适用材料并人工确认，再提交核验。P01、P02 可在同阶段并行；阻断推进的必办任务全部通过后解锁下一阶段。
5. 使用“根据当前资料起草文稿”整理填写内容，可编辑、保存版本和下载。文稿不代表主管机构许可；变更已确认资料会触发复核。
6. 进入“管理后台 → 办理流程”，选择四条路线之一，修改任务、字段、单选结果与通过值，再调试、保存草稿或发布。已有六堡茶业务保留创建快照。
7. 线下路线在展后同时开放买家跟进与 E08 展品核销。买家跟进完成后，核销可保持“待收尾”，正式订单继续办理；核销未完成时整项业务仍未结案。条件性任务须记录核验理由后才能选择“经核验不适用”。完整范围见 [六堡茶流程说明](LIUBAO_WORKFLOWS.md)。

资料库中的普通上传默认是业务材料。采集来源取得的主文件默认待审核；打开资料详情设置类别、法域、语言和生效日期，并完成审核后才进入问答依据。关联附件只保留文件，不参与解析和检索。

没有模型凭据时，助手明确采用演示规则；接入真实模型后，需要继续用正式法规与办理清单评测回答质量。完成本示例仅代表完成系统中的演示任务。
