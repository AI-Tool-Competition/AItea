# 五分钟体验

1. 打开工作台，选择“进入演示工作台”。当前只演示中国至印度尼西亚；模式 A/B 的业务差异尚待正式配置。
2. 在当前业务上传 `samples/product-profile.md`，用途选择“主文件”。原文会保存，解析成功后可以用于本次业务的检索和核验。
3. 打开“整理产品信息”，填写乌龙茶、茶叶、250 克、400 袋，勾选关联材料并确认适用于本批次，然后提交核验。
4. 点击“根据当前资料起草文稿”。可以编辑、保存新版本、查看历史和下载。改动已确认材料会要求任务复核。
5. 完成同阶段的“确认企业与联系人”。两个任务可按任意顺序办理；必办任务全部通过后，下一个主体阶段解锁。
6. 在对话里询问材料内容，展开引用查看原文位置。也可以尝试口述与材料不一致的净含量，查看冲突提示。聊天声称“已完成”不会替代核验。
7. 进入法务工作台，修改模式名称、节点、任务、字段、文稿模板和助手步骤。先校验与调试，再发布；已有业务不会变化，新业务使用新版本。

资料库中的普通上传默认是业务材料。采集来源取得的主文件默认待审核；打开资料详情设置类别、法域、语言和生效日期，并完成审核后才进入问答依据。关联附件只保留文件，不参与解析和检索。

没有模型凭据时，助手明确采用演示规则；接入真实模型后，需要继续用正式法规与办理清单评测回答质量。完成本示例仅代表完成系统中的演示任务。
