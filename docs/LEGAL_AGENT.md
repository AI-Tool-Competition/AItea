# 可编辑法律 Agent v0.1

本版把《法律问题分析业务规则.docx》的 QA-01 至 QA-06 转译为可配置的辅助分析流程。附件提供业务需求，不是运行授权或已审核法律资料。默认规则须由法务进一步细化；本版不宣称实现自动法律审查或完成各国法规采集。

## 使用入口

1. 进入已解锁的业务节点，主对话开头自动执行 QA-01 至 QA-06，展示实际步骤进度、缺项和办理建议。再次进入沿用有效结果，不重复生成；未解锁节点只提示前序要求。桌面与手机使用同一对话入口。
2. 在对话中的“补充信息”或“核对已记录的事实”展开编辑：填写必要缺项，分别处理用户确认与证据核验。证据核验需要选取可用主文件并记录核验说明；确认事实本身不会变成已核验证据。
3. 查看每个争点的结论、条件、来源、期限与后续行动。材料不足时保留附条件或无法判断，演示模式明确显示未调用大模型。
4. 在“编辑分析报告”中修改段落后保存。事实改变后，相关争点提示复核；重新分析会保留人工文字，同时列出更新建议。争点变化后失配的未保存文字会单独保留在“原争点未保存草稿”，可复制或确认丢弃。版本历史可查，旧窗口保存不会覆盖新版本。
5. 在节点分析编辑器的“法律规则”中调整规则卡。继承默认规则的阶段可选择编辑默认或单独配置；发布后只影响采用新版本的新业务，已有业务继续使用快照。

节点开始分析固定使用六步引擎，采用当前节点的法律规则或继承模板规则，记录与修订历史按节点隔离，事实在业务内共享。资料变化时自动更新同一份节点报告，人工文字仍然保留；“检查最新资料”可重新核对，失败或取消可重试。补充问题、历史记录、详细依据与报告编辑均在主对话内按需展开，运行中可停止。普通聊天是否再次使用六步分析由配置 `legal.enabled` 决定；普通指导会带上有效节点报告的摘要与人工修订，过期资料不沿用。启用后的流程画布、运行到步骤与调试检查点使用固定的 QA 编号，原有普通分析步骤仍保留以兼容旧配置。

## 保留的编辑点

| 编辑点 | 保存与重跑行为 |
| --- | --- |
| 规则适用领域、法域、条件、要求 | 随配置草稿及发布版本保存；不能关闭程序门禁 |
| 必要事实、来源与核验说明 | 独立修订号；事实冲突保留双方来源及处理记录 |
| 候选依据与有效性 | 使用资料库的不可变文件版本、国别、审核及适用期；模型不能自行授予审核状态 |
| 报告段落 | 保存人工正文；重跑产生独立建议，不覆盖人工编辑 |
| 测试问题、任务值、所选资料与预期 | 复用已有样例调试、历史对比及检查点恢复 |

## 六个模块

| 模块 | 职责 |
| --- | --- |
| QA-01 | 标准化问题，分别识别类型与领域，拆分争点 |
| QA-02 | 参考初步检索收集必要事实，区分提取、确认、证据与冲突 |
| QA-03 | 分开处理监管范围、法院/仲裁与准据法，形成允许范围内的检索候选 |
| QA-04 | 按候选检索并保留关联、原文定位、版本和未覆盖事项 |
| QA-05 | 组合领域及法域规则，比较成立条件、例外与抗辩，程序核算明确期限 |
| QA-06 | 展示结论、解释、依据与行动，保留条件和风险，不更改任务办理状态 |

条件状态为成立、不成立、待核实、不适用；结论为支持、不支持、附条件、无法判断。期限的法律性质、起算点、期间调整和日历需有依据；程序只在参数充分时计算，不能用计算出的日期反推法律适用正确。

## 运行边界

- 每批默认最多追问 3 项，可配置 1–5 项；复核默认 2 轮，可配置 1–3 轮。结构或引用范围校验失败仅有限重试，失败不会冒充演示成功。
- 每次最多 8 个争点；每业务本版最多载入和保存 600 条事实，覆盖六堡茶完整流程最多 402 个填写项，超限会阻止生成并提示整理。分析结果最多容纳 660 条事实，包含单次最多 60 条待核验抽取；超过保存上限的提取会明确提示。最多 60 张规则卡；附加法域最多 20 个，加来源国和目的国最多 22 个。
- 同一业务一次只运行一项法律分析，全局最多 4 项；请求记录和检查点有运行期限，超时中断可以重试。列表与版本历史分页读取。
- 保存事实即时核对最近 20 份分析，其余历史在读取时重新核对版本，避免一次编辑载入全部历史正文。
- 法律结论在本版始终保留人工复核标记；规则卡“额外复核”不能关闭这一门禁。本版没有法务签核完成流程，接受文字建议不代表批准法律结论。
- 未配置真实生成时只执行可验证的检索与程序步骤，输出演示标识。未配置 embedding 时使用词项检索。真实模型输出质量、法务规则覆盖与法条适用仍需单独评测。
- 引用来自已存储且符合权限、一级正文、审核与版本条件的资料。法规采集继续使用现有来源管理流程；初版不把空检索视为没有法律义务，也不证明全网检索完整。
- 本版保留有限复核和人工接管。Word 自动导入规则、主动全网扩展候选、外部提醒及合同审查起草不包含在本次交付中。
