# 业务、节点与会话工作区

工作台按“账号 → 业务 → 节点 → 会话”定位。左侧业务选择器支持两行名称，末项新建业务；默认只显示当前节点，其他节点按模板顺序折叠。每个节点保留一个引导会话及多个独立会话。资料入口统一在右侧当前业务的资料库，左下角只保留账号入口，直接进入账号管理。

业务资料统一展示，不区分主副文件；普通上传默认解析正文，不提供文件用途选择。资料库采用单行搜索，可切换文件名查找与正文检索，列表使用服务端分页。上传支持选择或拖入单份文件，上传完成后打开对应资料库并显示简短回执，正文预览按需打开。处理中资料在面板可见时自动读取最新状态，每批最多五份；关闭面板、切换账号或业务时取消旧读取，连续失败三次后等待手动重试。列表、上传回执和已打开的预览同步状态。历史仅保存原件的文件仍可下载；来源管理中的关联附件规则保留，解析完成不代表通过资料审核或业务核验。

来源管理使用连续列表，采集清单按国家、分类和关键词筛选，每页最多 20 项。点击条目打开详情，来源地址、候选资料、执行进度与采集要求集中在详情中；清单说明和配置操作按需打开。自定义来源默认只展示名称、最近采集与状态，添加表单只展开名称和地址，其余采集设置折叠；校验发现折叠区域有无效输入时自动展开。未保存草稿继续按账号隔离，关闭详情取消对应进度读取，列表在有进行中的任务时更新简短状态，并保留已经读取的较新进度。

## 引导与报告

引导会话先了解办理现状、参与主体及产品安排，邀请上传可用材料。没有材料不阻止分析。用户直接在会话中提出办理需求；助手按需在内部调用既有法律分析流程，报告产生后仍可继续对话。演示环境明确使用固定规则，不模拟模型调用。

每次引导分析保存不可变快照，并关联会话中的报告消息。原有可编辑法律报告仍由现有法律服务维护；其后续编辑不会改写历史快照。子任务通过服务端核验后，以任务修订号登记唯一分析任务，自动重新分析并追加报告。重复核验不会重复追加。失败保留原因，重试创建新的记录。

后台任务使用 SQLite 持久化队列及执行租约，单进程最多两个工作者，每次唤起最多处理四项。任务核验、会话列表、消息和分析历史读取会唤起待处理任务。服务重启后，过期租约可恢复执行；这不是独立常驻调度服务，停服期间不执行任务。

## 记忆与调用

- 会话历史：旧协议读取最近十二条消息；模型调度使用有界的完整历史前缀，缓存、容量及上下文预算见 [Agent 调度与记忆](AGENT_RUNTIME.md#对话缓存)。重试沿用已保存请求与响应。
- 节点共享记忆：使用其他会话带消息来源的摘要，先按问题匹配再按时间选取，最多六条；只用于补充讨论背景，明确标为未核实。任务进度从服务端重新读取。
- 业务与跨节点记忆：共享业务事实、确认事实、当前节点字段、上游完成或待复核任务和资料版本元数据；不直接复制其他节点全部聊天记录。用户讨论不会自动升级为确认事实、有效法规或完成状态。

上述设计参考 [LangChain 的 thread 与 namespace 记忆边界](https://docs.langchain.com/oss/python/concepts/memory)、[Anthropic 的上下文整理与结构化笔记实践](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)及 [Mem0 的选择性持久记忆研究](https://arxiv.org/abs/2504.19413)。本实现采用现有 SQLite 和有界检索，不引入新的外部记忆服务。

配置生成模型后，会话由模型自主选择并组合办理指导、资料核对、法律分析、文稿起草和节点交接工具，也可发现联网搜索、识图和 RAG 工具。能力选择、法律模式和记忆管理均不作为用户操作入口；法律结论仍使用既有法律引擎。演示与旧协议保留规则路由。内部记忆、上下文压缩及流式进度展示规则见 [Agent 调度与记忆](AGENT_RUNTIME.md)。调用展示对应真实执行过程，未配置的模型能力按演示规则说明。文稿意图创建真实文稿及版本，后续可在右侧预览 Markdown、编辑、下载。版本冲突保留本地输入，核对服务器版本后才能保存。

## 数据与兼容

结构版本 17 新增节点会话、消息关联、来源记忆和引导运行表，版本 18 新增报告与消息关联。已有聊天按业务、节点归入“原有会话”，保留原消息及幂等响应。后续 Agent 结构升级和备份兼容范围见 [Agent 调度与记忆](AGENT_RUNTIME.md)，旧库通过正常服务初始化升级。所有会话、记忆、报告及文稿请求均检查账号、业务和节点范围。

资料库预览统一使用连续阅读页：标题、简短解析状态、下载入口，以及解析后的正文、表格和受保护图片。已有摘要直接展示，缺失的摘要和图片说明不补造。页面不展示版本、法规关联、审核表单、解析统计或隐私说明。后台资料库固定为法律总库，仅提供国家与名称筛选和内容预览；业务上传仍从工作台完成。历史版本、引用资格和资料归属仍由服务端保存与校验。
