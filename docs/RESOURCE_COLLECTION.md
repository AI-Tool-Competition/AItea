# 服务器并发资源采集

从当前 worktree 根目录执行。工具复用 `ChecklistService`、`CollectionWorkers`、安全下载器、内容寻址原件、受限解析和持久任务，使用全新的工程采集账号及独立资料目录。资料保持草稿；候选的自动抽样不判断法源等级、适用期或条约效力。

## 启动与范围

```bash
TEA_COLLECT_WORKERS=16 TEA_COLLECT_PER_HOST=2 make collect-resources \
  OUTPUT=data/campaigns/indonesia-server \
  ORIGINALS=2 BATCHES=1 BUDGET=600
```

默认覆盖当前方案的全部 29 类；`ITEMS=1.3,4.1,4.2,5.3` 可限定条目。`ORIGINALS` 是每类最多尝试的正文候选数，范围 0–20，默认 0 只发现目录；它不是成功原件数。`BATCHES` 是每类发现批次数，范围 1–20，每批沿用 40 个页面的上限。`BUDGET` 为本次运行的秒数，范围 10–7200。模型默认关闭；原件、部分正文、待 OCR 页及待核对页分别计数。

下载数仍限制为 1–16，每域真实连接为 1–4，解析任务为 1–2。各类独立推进：一个条目完成发现后即可下载原件，不等待其他站点。下载领取按任务最近推进时间轮转，让同域多个资源类别都有机会执行。下载、解析及网络连接名额仍由已有事务和租约控制。

条件条目只在命令行明确提供 `--confirm-items` 后执行；专用数据核验及缺适配条目保留跳过原因。目录和正文使用已有可信域名、路径、HTTPS、DNS 固定、重定向、体积及重试限制。

## 续跑与扩量

预算耗尽或进程中断后，使用相同目录、方案、条目、模型模式和采集上限继续：

```bash
TEA_COLLECT_WORKERS=16 TEA_COLLECT_PER_HOST=2 make collect-resources \
  OUTPUT=data/campaigns/indonesia-server \
  ORIGINALS=2 BATCHES=1 BUDGET=600 RESUME=1
```

明确增加采集预算时加 `EXTEND=1`；普通抽样只允许提高批次数或候选数，继续使用同一账号、已存原件和目录检查点：

```bash
TEA_COLLECT_WORKERS=16 TEA_COLLECT_PER_HOST=2 make collect-resources \
  OUTPUT=data/campaigns/indonesia-server \
  ORIGINALS=3 BATCHES=2 BUDGET=600 RESUME=1 EXTEND=1
```

终态范围已执行完的普通续跑不会重新发起任务。扩量保留已尝试候选及旧任务；不重复选择同一候选，不重建资料库。方案或条目发生变化应创建新采集目录。原站失败仍使用已有有限重试，扩量不表示访问限制已解除。

同一目录只有一个协调器可运行。首次执行拒绝非空目录，续跑要求有效检查点及对应工程账号。提交意图先保存，再以固定请求标识提交业务事务；重启可以恢复“事务已提交、检查点尚未更新”的请求。预算结束仅终止本次创建的进程组，保留数据库、原件和分段。强制中断后的在途工作会等待原有租约到期后重新领取，通常最多 120 秒，长下载资格以已有任务设置为准。

## 模型与结果

已有 HTML 原件的正文图片使用独立、有界入口采集。指定已有资料库、账号和 1–20 个文档 ID；默认只下载并绑定原图，不请求模型：

```bash
uv run --project backend --locked python scripts/collect_html_images.py \
  --data-dir data/campaigns/已有资料库 --owner 已有账号ID \
  --document-ids 文档ID1,文档ID2 --output data/verification/网页图片任务 \
  --images-per-document 4 --max-downloads 20 --time-budget 300
```

同目录续跑加 `--resume`，账号、文档、下载范围及模型模式必须一致。真实识别与一级向量化需同时指定 `--live-models --models-env /绝对路径/私有模型配置.env`。处理只领取所选账号中具备当前 HTML 原文映射的草稿，普通附件、已审核资料、其他格式及其他账号任务不参与；下载队列保持关闭。事务领取、模型处理和检查点保存均重验资格。已有合法排队任务可以恢复，不因绑定阶段正在处理而重新下载原图。

图片选择须先从真实父原件复核正文 DOM、原文字符位置和唯一 `img/src`；导航图、响应式候选、脚本对象、视频及未知边界继续报告缺口。HTTPS、公网 DNS 固定、重定向、体积、实际主机连接租约与限流等待沿用已有下载器。每次最多 100 次受保护下载尝试，单图 8 MiB、每批原图 32 MiB、两个下载线程；90 秒单次截止仍受整个任务预算约束。通用二进制 MIME 还须通过受限子进程的完整单帧 PNG/JPEG/GIF 解码，不能凭扩展名或 MIME 放行。

下载意图、结果和原件 CAS 先保存，再绑定、排队和调用模型。意图及完成收据还通过账号隔离的不可变链接保存在 `files/html-image-transfer-receipts/`，独立于任务的可变 `images.json`；主检查点写入失败后，新进程可核验收据和原图，避免重复成功下载。中断意图没有可验证完成收据时保留 `HtmlTransferUnconfirmed`，停止自动重复请求，先核对原下载状态。成功绑定将实际 HTTP 元数据收据加入原文映射，此后可移除匹配的活动检查点；失败或未绑定项继续保留，避免有限检查点数量挡住长网页续跑。收据记录响应属性，不冒充完整原始 HTTP 响应或模型原始响应。文本完整与当前输入／模型指纹一致的向量数量分别验收；范围内仍有源、解析或向量缺口时返回 2，预算耗尽返回 3。

真实 OCR／向量需显式启用，并提供后端模型配置：

```bash
uv run --project backend --locked python scripts/collect_resources.py \
  --output data/campaigns/indonesia-models \
  --items 1.1,4.1,5.3 --originals-per-item 2 --time-budget 600 \
  --live-models --models-env /绝对路径/私有模型配置.env
```

模型文件只读取既有生成、embedding、rerank 和视觉 OCR 配置；OCR 还要求 `VISION_OCR_ENABLED=true`。凭据不进入检查点、报告或版本库。原生 PDF 解析启用锁定 `pypdf[fonts]` 的 CFF 字体映射；这是 pypdf 提供的可选依赖，参见 [6.20.0 官方依赖声明](https://github.com/py-pdf/pypdf/blob/6.20.0/pyproject.toml)。正文不完整或存在识别疑点时继续受既有索引门禁约束。

输出包括 `campaign.json`、`report.json`、`worker.log`、`tea.sqlite3`、`files/` 和完结时的资料目录快照。续跑前保存前一轮报告快照，保留之前的耗时、范围和失败记录。报告按条目记录目录、候选、原件版本、字节数、正文完整性、待识别／核对页和有限错误样本；完成时逐份重新验证账号路径、SHA-256 和大小。失败及预算耗尽的结果继续保留。

| 退出码 | 含义 |
| --- | --- |
| 0 | 本次限定范围执行结束且样本完整，不代表全国或全站收齐 |
| 1 | 协调器或内部验证失败，查看报告 |
| 2 | 范围执行结束，仍有缺候选、缺原件或正文质量缺口；非法命令参数也返回 2 |
| 3 | 本次预算耗尽，可使用同一检查点续跑 |
| 130 | 用户中断 |

## 两份清单、两级映射和真实模型

印尼与新加坡分别使用 `indonesia-20261003` 和 `singapore-demo-20261009`。新加坡的 16 项原文要求来自 2026-10-09 附件，原件 SHA-256 已固化；当前 v7 启用 15 项活动任务，SSO 的 1.1–1.3 已随 2026-10-25 代理复核恢复，v6 快照保留移除时状态。SG-LegalCite 2.1 仍不可访问并保留为缺口，完整定义见 v5 快照。印尼 v16 启用 16 项活动任务，UUD 1945 入口因代理超时或 403 保留在 v14 快照；运行中发现交通部和 Treaty Room 有原件超过通用 20 MiB 上限，v16 仅为这两项设置 128 MiB 与 900 秒下载限额，既有任务快照保持原样。印尼附件与已有清单来源校验值相同。清单中的截图是入口定位资料，不能当作法规正文。

方案中的原文备注反映附件编制时的范围与状态，当前采集进度以各运行目录的报告为准。既不将附件内容作为执行指令，也不以工程样本缩减现行法规、附属立法或全部条约附件的采集范围。

默认抽样用于工程诊断。业务材料使用 `--selection` 指定原件 URL、一级／二级用途、`primary_keys`、`evidence_url` 和 `locator`。选择文件绑定清单 ID 与附件 SHA-256；不允许跨国 URL、缺一级锚点、未知原件路径、重复分级或超预算。选择模式最多 200 份材料、每项最多 200 次原件尝试；新加坡监管组仍不得超过 45 份。它只收录指定原件，发现的其他候选留在核验队列。

```bash
uv run --project backend --locked python scripts/collect_resources.py \
  --plan-id indonesia-20261003 \
  --output data/campaigns/indonesia-tiered \
  --selection config/collection-selections/indonesia-tea-20261013.json \
  --discovery-batches 2 --originals-per-item 30 --time-budget 1200 \
  --live-models --models-env .dev/models.env
```

新加坡替换方案、输出目录和选择文件为 `singapore-demo-20261009`、独立目录及 `config/collection-selections/singapore-tea-20261013.json`。模型文件为权限 0600 的后端配置，只提供 `LLM_*`、`EMBEDDING_*`、`VISION_OCR_ENABLED=true`；按服务实际吞吐设置 `EMBEDDING_BATCH_SIZE`，本次 4 条输入实测成功。密钥不进入正文、报告或版本库。

二级原件可以在一级原件已保存、仍在向量处理时启动。普通文件附件与二级法律材料分开：前者仅存原件，后者保留解析文本。二级指向已有同国一级文档；写入 `related` 前核对已保存官方来源页面同时包含两端原件链接，并保存页面哈希、两端文档版本与哈希。该用途关联不推定引用、母法授权、批准、实施或修订关系。缺少共同来源证据就报告未映射，不补造关系。

预算结束或中断后，提供相同方案、选择文件、模型模式和原有额度续跑。调整请求批量后，可额外提供 `--resume --retry-embeddings`，只重排该账号、该方案内文本完整的失败一级向量任务；不清除 OCR 待核页面、不重下载原件、不重建数据库。每次重试及前一轮报告保留。

最终私有 inventory 除原件和目录记录外，还导出 `texts.jsonl`（两级正文、分块和原文定位）、`relations.jsonl`（固定版本关联）、`ocr-pages.jsonl`（原件页—识别图—文本状态）、`ocr-regions.jsonl`（裁剪范围和复核证据）。正文不含内嵌向量；原件和图片继续留在账号内容寻址库。报告独立统计一级／二级原件、完整文本、当前模型的向量、一级向量完成、二级向量异常和未映射关系。

真实向量生成不等于法律审核。采集资料保持草稿，正式 RAG 继续要求国别、一级用途、完整正文、当前版本、已审核和适用期间。SSO 403、动态目录、缺少附件、模型失败和不清晰图片保留具体缺口；现行法规全量范围与本次选定原件完成情况分别衡量。SG-LegalCite 须取得完整 CSV、核真实表头及逐年数量、筛主题并经人工核法律命题；未完成该流程时不能把任务标为已入 RAG。

`--resume --revalidate-layout` 用受限解析重新核对原件几何，仅撤回经原件证明的表格误判；原生文本必须完全一致，实际表格或独立模型不完整警告继续阻止完成。识别文字、页图和原件版本保持不变，旧警告及页面哈希保存在复核记录中。独立注释框、封面装饰和流程图不因横竖线数量被强制视为表格；真实网格和合并单元格继续接受布局验证或 OCR。

## 官方技术资料与实践对应

本轮查阅资料用于核对现有实现和真实失败样本，未替换技术栈或新增抓取框架。

- [Scrapy 并发节流说明](https://docs.scrapy.org/en/latest/topics/autothrottle.html)强调按站点分配并发，并在错误出现时放慢。本项目复用持久连接配额、实际重定向主机的冷却和有上限的退避；本轮没有实现按响应延迟自动调速。新来源先用低额度取得有效样本，再通过 `--extend` 扩量。

- [pdfplumber 表格算法](https://github.com/jsvine/pdfplumber#extracting-tables)说明线段合并、交点与单元格重建；[PyMuPDF 表格策略](https://pymupdf.readthedocs.io/en/latest/page.html#Page.find_tables)说明背景矩形可能造成误判。本轮复用已有线段聚类，检验实际连通边界，保留合并单元格的 OCR 门禁；边界复杂、无框表格和阅读顺序仍需单独验证。
- [HTML 页头及页尾语义](https://html.spec.whatwg.org/multipage/sections.html#the-header-element)说明它们可以属于正文文章。本轮网页提取优先使用实际 `main` 元素，排除站点导航，保留文章标题、发布日期和出处；注释、脚本与模板中的同名字样不决定正文区域。回归样本先复现了标题丢失与空正文，再验证修复；该验证不代表所有官网 HTML 布局均已覆盖。

Embedding 对超时、413/408/504 有界缩小批量，并记住该进程、该模型服务已证实的批量上限。429 按服务等待时间进行冷却，真正请求才消耗请求尝试；未发起请求的冷却等待不消耗尝试。已发出请求后遇到等待仍计实际尝试，不能用延期丢掉请求记录。鉴权和永久错误不重复重试，向量必须保持输入顺序、有限非零数值、正确维数和当前指纹。批量缓存有上限，凭据仅用于内存哈希键；重启后重新学习。已有向量按分块持久保存，预算结束后继续处理剩余分块，不能生成占位向量或伪造吞吐。
