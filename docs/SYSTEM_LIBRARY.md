# 系统法规总库

采集得到的官方法规归入当前实例的 `data/tea.sqlite3`，由固定内部身份 `aitea-system-legal-library` 持有。该身份没有邮箱、密码或登录会话，也不代表某个商家的账号。没有新增数据库表或结构版本。运营导入明确调用 `system_library.ensure_principal(conn)`，并使用现有不可变原件、国家分类、元数据、关系与检索索引服务；应用启动不会擅自建立账号或搬迁原件。

总库接收已定国的官方 HTTPS 原件。印尼政府 `.go.id`、新加坡政府 `.gov.sg` 与采集计划明确列出的官方国际组织文件域由服务端固定允许；网址认证信息、非 HTTPS、非标准端口及未配置的域名被拒绝。该检查只确认来源身份，抓取仍必须经过现有公网地址、重定向、大小和超时限制。实际入库前还需核对下载收据、原文身份、版本及文件哈希，不能把官方新闻或任意网页当作法规。网页、文件、标签和请求不能扩大受信域。

登录用户在选择国家后可读取总库列表、正文、下载、历史版本和原文关系。业务资料列表按业务目标国家包含对应总库原件，其他国家原件不混入。返回 `source_scope=system`，页面显示只读状态。用户自己的资料继续属于自己的账号；公开读取不会授予修改、审核、分类、删除、建立关系或添加附件的权限。总库也不向匿名用户开放。

一、独立二级法规使用文件角色 `primary` 与法规分类 `secondary`，可保存文本和定位映射，但不进入向量与 RAG。

二、普通关联附件使用文件角色 `secondary`，必须属于同一系统主文件和国家，只保存原件；没有正文解析、索引或处理任务。

三、一级法规的向量仍绑定原件哈希、不可变版本、切片输入及真实模型标识。共享检索要求一级分类、最新或明确历史适用版本、完整且当前的文本索引、已发布审核、有审核时间及真实非体验审核人员、已知生效起日和请求日期适用性。系统内部身份不能代替人工审核。

四、草稿、未核定适用日期和解析不完整资料可展示采集状态，不自动作为有效法引用。新增版本不会覆盖历史原件；新版本待审核时，默认检索不能自动退回旧版本冒充现行依据。

法律分析保留用户资料和总库资料的不同权属。相关国家总库的原件版本、审核、分类和索引修订纳入分析快照，发生变更后既有分析需要重新核验。本文不表示现有采集原件已经完成法务审核或生产发布。
