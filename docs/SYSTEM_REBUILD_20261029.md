## 新工作树实现

一个主 Agent 直接读取证据、分析和答复；普通问答移除强制 Task Brief、法律子报告、报告转换和常规第二次润色。法律取证提供搜索候选、读取原文、取得版本关系，业务核验、状态和事务仍归原有应用服务。常用工具直接提供参数定义，方法和长尾能力按需读取，MCP 复用相同权限和收据。

后台采集、解析、向量索引和官方版本导入使用独立进程；聊天 API 默认不启动这些队列。本轮没有启动真实付费采集或嵌入队列，继续读取已有索引。历史人工研究及报告编辑保留原接口，普通聊天不会启动它们。

本轮另修复来源名称问题：把网页站点标题与法规名称分开保存。资料目录标题呈现为“全球法规网”“政策法规库”等网页名称时，若同版本正文首条记录提供明确规范标题，就按该标题展示并附标题证据记录编号；未取得标题时标记名称待核对，保留网页原名，日期和效力继续保持未知。该处理不根据正文议题猜测法名，不将网站标题解释成法律层级。
