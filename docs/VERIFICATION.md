## 实际浏览器验收

使用生产构建后的页面和真实本地 API 操作，检查了以下场景。这些是浏览器操作记录，不是已建立的完整自动化端到端回归套件。

- 演示账户创建独立业务；刷新及服务重启后，会话与业务数据保留。
- 主资料上传后完成解析与检索，引用显示原文位置和版本，原件可下载。
- 填写产品信息、关联材料并核验任务；同一阶段任务可分别办理，必需任务完成后解锁下一阶段。
- 文稿生成、编辑、离开页面后恢复草稿、保存新版本；关联材料变更后任务重新要求核验。
- 对话按阶段保存，业务资料按所属业务隔离；侧栏切换后可继续原有办理过程。
- 资料类别、法域、有效期和审核状态可编辑；未审核的法规演示文件不进入回答检索结果。
- 法务工作室可校验、调试、导出和重新导入配置；发布后，新业务使用新版本，已有业务保留原快照。
- 演示账户转为注册账户后保留业务；退出并重新登录可继续使用。
- 不允许采集回环地址，来源页面展示失败原因；停用来源后不会参与周期采集。
- 旧工作区入口重定向到茶业务页，未接入的上游 API 不会被转发到其他服务。
- 桌面及 390 × 844 手机视口检查通过，手机视口没有横向溢出；业务目录、流程抽屉与配置页面可操作。
- 最后一次生产页面检查未捕获浏览器 `pageerror`。

本地截图保存在被 Git 忽略的 `output/playwright/`，包括 `final-desktop.png`、`final-mobile.png`、`flow-mobile.png`、`studio-mobile.png`。

## 容器与启动验收

API 镜像 `aitea-api:local` 已实际构建，容器使用非 root 用户。容器内验证了健康检查、未登录请求拒绝、演示登录、TXT 上传与检索、任务核验、文稿下载、超限请求拒绝和退出后会话失效。最后一次后端修改后重新构建，并复验健康检查与实际文件上传。

前端已实际完成本地生产构建，并通过 `make start` 对应的启动器运行；完整 Web 容器镜像和整套 Compose 联合启动尚未实测。启动器验证了端口占用提示、正常退出及重启，不会停止其他项目的服务。

## 仍需要业务资料或运行环境的验证

- 尚未提供正式的两种业务模式、经过审核的中国／印度尼西亚法规清单及具体办理要求。现有配置和示例文件只供演示。
- 未提供生成模型和向量模型密钥，因此本地浏览器验收使用明确标识的演示助手与词项检索。接口适配和失败降级已实现、已用测试覆盖，真实供应商连通性、输出质量和检索召回仍需在接入后验证。
- 基础解析支持可提取文本的 PDF、DOCX、HTML、Markdown 和 TXT。可选 Docling／OCR 路径尚未进行真实扫描件与模型环境验收；二级附件只保存原件，不解析或向量化。
- 当前是单节点、持久化的演示系统基础。公网部署、备份恢复演练、多实例调度、容量与性能压测，以及完整上游功能回归不在本次已完成验收范围内。
